1. 关键概念
1.1 三方博弈：需求方、供给方、受众
1. 需求方(demand)：广告主，或者代理商、采买方
2. 供给方(supply)：媒体，或者广告变现平台
3. 受众(audience)：用户
1.2 广告分类：效果广告、品牌广告
1. 目的：效果广告、品牌广告
2. 形态：展示广告、搜索广告、信息流广告
1.3 付费方式：CPM/CPC/CPA
1. CPM(cost for mille): 千次曝光成本
2. oCPM(optimized cost for mill)：优化后的千次曝光成本
3. eCPM(estimated cost for mille)：预估的千次曝光成本
4. CPC(cost for click)：单次点击成本
5. CPA(cost for action)：单次转化成本
1.4 oCPM = CPA * pCTR * pCVR * pacingFactor
1. oCPM：optimized cost per mille，优化后的千次曝光价格
2. CPA：cost for action，广告主为一个转化目标提供的价格
3. pCTR：predict clickthrough rate，系统预估的广告点击率
4. pCVR：predict conversion rate，系统预估的广告转化率
5. eCPM = oCPM * 1000 = CPA * pCTR * pCVR * 1000
6. 可以看出oCPM广告，包含了CTR模型、CVR模型、广告预算相关的pacing模块

2.3.1 Bid Landscap

2.3.2 Bid Strategy
负责综合广告主的价值预估和流量的成本预估，目标是在预算限制下优化广告主价值的利润，基本原则：应该竞得成本低但广告主价值高的流量，差值越大越应该竞得它。
$$max\sum{((advertiser\_value - win\_price) * win\_rate)}$$
2.4 Calibration - 让广告模型预估的更准
广告模型的目标是预估CTR和CVR，并把预估偏差作为评估指标；推荐模型的首要任务是把排序做的更好，预估目标则是跟用户参与度最相关的业务指标；搜索非常看重能够把“正确”答案给召回回来，围绕搜索词高效获取问题；总体来说，广告算法要“估的更准”，推荐算法则是要“排的更好”，搜索算法是要“搜的更全”。
Calibration是要在CTR、CVR预估不太准确的时候，把预估值强制地纠偏到后验结果上，其中后验结果可以通过label统计的方式获取。
比较经典的calibration方法是保序回归，在不改变预估值排序的前提下，通过调整预估值让模型的输出更接近后验结果；针对深度学习模型本身的calibration方法也层出不穷，例如Calibrating CTR Prediction with Transfer Learning in Instacart Ads等。
[图片]
基于负采样修正，其中负样本的采样率为1:r，预估结果为pCTR；
pCTR = sigmod(w*x + b) = 1/(1+exp(-w*x - b))
pCTR' = pCTR/(pCTR + (1-pCTR) * r) = 1 / (1 + r*(1/pCTR-1)) = 1 / (1 + r*exp(-w*x - b))
pCTR' = sigmod(w*x + b - ln(r))
b' = b - ln(r)
2.5 样本转化延迟 - 困扰广告多年的顽症
应对转化样本回传延时问题，比较实用的方法是延迟下发正样本+calibration的方案解决。当模型收到点击样本的时候当做负样本使用，在收到延迟转化样本后当做一个正样本去训练，并在模型之后通过calibration模型纠偏。
阿里提出了一种叫做Bi-DEFFUSE的模型结构，分别预估转化窗口内的CVR和转化窗口外的CVR，然后预估最终CVR的时候再把二者加起来，Asymptotically Unbiased Estimation for Delayed Feedback Modeling via Label Correction

3. 附录：相关术语
1. 频次控制：指控制一个用户最多在指定时间段内看到一个广告（或相似广告）的次数
  1. 降低频次，
  2. 达到门限则彻底退出
  3. 提高受众数量；提高CTR，大约4次后选择性忽视；提高CVR，在第一次展示时最高，4~6次基本转换；
2. cookie介绍
  1. Cookie是指某些网站为了辨别用户身份，进行会话信息而存储在用户本地终端上经过加密的数据。最初的目的是解决用户频繁登录同一个网站时打开页面速度慢的问题。
  2. Http协议是无状态的，服务器无法记录用户的上一步操作，因此在用户第一次访问服务器时，会生成一个session ID来标识用户并保存信息，具备唯一性。结合用户使用状态，形成一段文本发送给客户端，在下次请求访问时，发送该cookie给服务器，可以实现快速打开服务器内容，提升用户体验。
  3. Cookie分为第一方cookie和第三方cookie，前者是指用户访问服务器时创建的，后者是第三方数据公司征得网站同意后，设置的独立cookie，以便收集用户数据，实现对数据的跨域使用。例子：用户访问某电商平台后，当浏览其他网站时，会出现购买过的物品购买链接。
  4. Cookie本质上是对用户上网数据和行文的记录和存储。利用cookie数据，媒体可以对用户进行个性化深度分析，按照广告主需求锁定目标受众，实现广告的精准投放，从而减少广告投入成本。
  5. 利用cookie数据精准锁定目标人群（受众定向是精准营销的基础，匹配用户、上下文和广告）。根据用户和上下文，推送个性化广告，确定推送时段和投放频次，使广告有更高的到达率和转化率。推动广告的精准定价。


基础术语
1. 每个广告(Ad)有一个出价(Bid)，在某种情形下有点击率(click-through-rate,CTR)，计费方式包括：
  1. 按点击收费（ChargePerClick，CPC）
  2. 千次展示收费（CostPerMille,CPM)
  3. 预估点击率（PredictCTR，PCTR）
2. 目标分类：
  1. 广告具有准入门槛，有相关性需求
  2. 搜索则没有准入门槛，只是位置有先后区别
  3. 二者的区别，原因就是广告位资源有限点击率
3. 计算广告收入公式：
  1. eCPM=PCTR*CPC，不过实际中不会单纯依赖eCPM，一般还有质量得分（quality）
4. 频次控制：指控制一个用户最多在指定时间段内看到一个广告（或相似广告）的次数
  1. 降低频率
  2. 达到门限则彻底不出
5. 提高广告收入：
  1. 提高受众数量；
  2. 提高CTR，大约4次最选择性忽视；
  3. 提高CVR，在第一次展示是最高，4~6次基本转化。
