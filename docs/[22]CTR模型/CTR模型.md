传统推荐系统算法(一):协同过滤(Collaborative Filtering，CF)-CSDN博客
基于用户的协同过滤(UserCF)：给用户推荐和他相似用户喜欢的物品
基于物品的协同过滤(ItemCF)：给用户推荐和他喜欢物品的相似物品
1. 用户物品共现矩阵：r_ij = {0, 1}，表示用户i对物品j的评分；
UserCF:
1. 用户相似度：在共现矩阵中，行向量代表一个用户对所有商品的评价，如果计算用户i与用户k的相似度，等价于计算行向量i和向行量j的相似度；
  1. 余弦相似度
    s_ik = sim(u_i, u_k) = u_i*u_k / (||u_i|| * ||u_k||)
2. 皮尔逊相关系数：为了减少用户偏置的影响，在余弦相似度的基础上减去用户评分偏置
    s_ik = sim(u_i, u_k) = (u_i-u_i_mean)*(u_k-u_k_mean) / (||u_i - u_i_mean|| * ||u_k - u_k_mean||)
2. 排序结果：根据用户间的相似度，选择出top-k相似用户，然后再预测用户对物品的评价预测值，最常用的方法是利用用户相似度和用户评价的加权平均和作为预测结果；
  p(i,j) = u_i_mean + sum(s_ik * r_kj) / sum(s_ik)
ItemCF:
1. 物品相似度：在共现矩阵中，列向量代表一个物品的所有用户对它的评分，计算物品i和物品j之间的相似度，就是计算列向量i和列向量j之间的相似度；
2. 排序结果：根据用户行为正反馈的物品中，选择k个相似物品；
