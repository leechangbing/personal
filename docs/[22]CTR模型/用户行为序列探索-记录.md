2020/06/30: self-attention计算
self-attention的计算过程可以完全依靠矩阵计算实现：
1. 高纬矩阵乘法规则： A[batch_size, a, b] 则B的shape一定是[batch_size, b, c], tf.matmul(A, B) 得到 C[batch_size, a, c]
2.  可以确定第一维的size一致m, 后面的维度和二维矩阵乘法一致
3.  实现方式：attention = tf.matmul(A, tf.tranpose(A, [0, 2, 1])
4. softmax计算： 默认以最后一维度计算
 计算权重：weight = tf.nn.softmax(attention)
1. 计算输出： output = tf.matmul(weight, A)
  self-attention的计算方式依靠循环实现：
  输入：A[batch_size, seq_len, embd_size]
  输出：B[batch_size, embd_size]
1. 对batch_size循环
outputs =[]
scale = A.get_shape().as_list()[-1]  ** 0.5
for i in rang(batch_size):
        x = A[i, :, :]                                                         //[len, embd_size]
        w = tf.matmul(A, tf.tranpose(A)) / scale           //[len, len]
        w = tf.nn.softmax(w)                                         //[len, len]
        y = tf.matmul(w, A)                                            //[len, embd_size]
           outputs.append(tf.reduce_sum(y, axis=0))       //[batch_size, embd_size]
2. 对len_seq循环
outputs = []
scale = A.get_shape().as_list()[-1]  ** 0.5
for i1 in range(len_seq):
        x1 = A[:, i1, :]                                                          //[batch_size, embd_size]
        out1 =  []
        weight1 = []
        for i2 in range(len_seq):
                x2 = A[:, i2, :]                                                  //[batch_size, embd_size]
                w12 = tf.reduce_sum(x1 * x2, axis=-1)          //[batch_size]
                w12 = tf.expand_dims(tf.exp(w12), -1)          //[batch_size, 1]
                o12 = x2 * w12                                               //[batch_size, embd_size]
                out1.append(o12)                                          //[batch_size, embd_size]                weight1.append(w12)                                    //[batch_size, 1]
        outputs.append(tf.add_n(out1) / tf.add_n(weight1) )   //[batch_size, embd_size]

2020/06/11：模型修改思路
根据
用户行为：曝光，点击，转化，
时间周期：短期，中期，长期
兴趣强度：弱， 中, 强
稀疏程度：强， 中， 弱
广告场景与推荐场景下的不同之处：
1， 广告场景下的用户行为数据比较稀疏，点击率约为千分之一；
2，推荐场景下的物品是用户所需的商品，即符合用户意图，尤其是在垂直领域中（例如淘宝，美团，抖音）
3，推荐场景下的用户行为的具有较强的连续性和单一性，用户在短期时间内的沉浸式浏览，具有很高的注意力，使得用户在短期内的兴趣集中且专一（例如广告一般连续每隔6/3条内容，插入一条广告）；
用户行为数据稀疏的原因：
1，广告内容并非完全用户所感兴趣，需要兼顾广告主和用户的利益，而且广告本身也带有目的；
2，页面布局，使得用户很难做到沉浸式使用；
原因：推荐场景和广告场景的商业目标不同，
1，在推荐场景下，系统与用户的目标一致，因此推荐的物品总是以用户兴趣为目标；
2，在广告场景下，系统与用户的目标不一致，系统需要同时兼顾广告主与用户的利益，推荐物品以期望收益为目标；
处理：
1，构造不同时间长度和不同行为类型的的用户序列， 涵盖短期的曝光序列，中期的点击序列，和长期的转化
2，对于兴趣较弱的曝光行为数据和数据稀疏的转化数据，进行pooling处理
3，对于兴趣中等和较稠密的点击数据进行self-attention处理，
4，对抽取的不同层次的兴趣和目标广告交互，进行qk-attention处理，或构建NN, 抽取兴趣的表达相关度
