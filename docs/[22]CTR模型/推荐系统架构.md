1. 推荐框架
[图片]
[图片]
[图片]
召回：根据用户特征，从海量物品库中，快速召唤一部分用户潜在感兴趣的物品；
粗排：通过少量用户特征和物品特征，在保证一定精准的前提下，通过简单模型进行粗略排序；
精排：使用所有可能有用的特征，在算力承受速度极限的前提下，尽量精准地对物品进行个性化排序；
重排：主要是技术产品策略主导或者为了提升用户体验，比如去除已读、去重、打散等；
2. 召回(recall)
[图片]
[图片]
个性化召回核心思想：将用户特征和物品特征分离，通过模型分别计算出用户embedding和物品embedding，在线上根据用户embedding快速检索与用户兴趣匹配的物品。
理论上，任何有监督模型都可以用来做召回模型，比如FM/FFM/DNN等，“双塔”模型指的是用户侧和物品侧特征分离分别打出embedding的结构而已。
另外，在召回模型应该与排序模型相同的优化目标，尤其是如果排序阶段采用多目标优化的情况下，召回模型也应该采取相同的多目标优化。否则，如果优化目标不一致，很可能会出现高质量精排目标，在前置环节被过滤掉，影响整体效果。
典型工作
1. FM模型召回：推荐系统召回四模型之：全能的FM模型
2. DNN双塔召回：Sampling-Bias-Corrected Neural Modeling for Large Corpus Item Recommendations
2.1 用户行为序列召回
[图片]
[图片]
用户在使用APP或者网站的时候，会产生一些针对物品的行为，例如点击、收藏、互动、购买等，而不同类型的行为则代表了不同程度的兴趣。
用户行为物品序列，能够从细粒度表征用户兴趣。在用户兴趣建模的过程中，输入是用户行为物品序列，可以使用物品ID表征，也可以融入一些side information，例如名称、描述等，将这些信息融合为一个embedding就该表了用户兴趣。
在用户行为物品序列中，是具有时间序列的。理论上，任何能够体现出时序特点或者特征局部性关联的模型，都比较适合，典型的比如CNN、RNN、Transformer等。目前很多实验表明，GRU可能是聚合用户行为序列效果最好又比较简单的模型。
在召回阶段，如何根据用户行为序列打embedding，可以采用有监督的模型，比如Next item prediction的预测方式，也可以采用无敌监督方式，例如sum pooling。
典型工作
GRU：Recurrent Neural Networks with Top-k Gains for Session-based Recommendations
CNN：Personalized Top-N Sequential Recommendation via Convolutional Sequence Embedding
Transformer: Self-Attentive Sequential Recommendation
用户行为兴趣embedding拆分，相较于单用户兴趣embedding来说，就是把用户行为序列打到多个embedding上，实际上类似聚类的过程，把不同的item放到不同的兴趣类别中。用户兴趣拆分可以很大一定程度上缓解头部问题，即召回物品集中在强势情趣上，造成弱势兴趣不太能体现出来。
典型工作
召回：Multi-Interest Network with Dynamic Routing for Recommendation at Tmall
排序：Practice on Long Sequential User Behavior Modeling for Click-Through Rate Prediction

3. 排序(rank)
[图片]
模型表达能力：代表了模型是否具备充分利用有效特征以及特征组合的能力，显式特征组合、特征抽取器、增强学习技术、AutoML自动探索模型结构是这方面明显的技术进化方向。
模型优化目标：体现了希望系统去做好什么，往往与业务目标有关联，多目标优化以及ListWise最优是目前最常见的技术进化方向；
特征和信息融合：如何采用更丰富的新类型特征，以及信息和特征的扩充融合是主要技术进化方向，用户长短期兴趣分离、用户行为序列数据的使用、图神经网络、多模态融合等是这方面的主要技术趋势。
3.1 显式特征组合
[图片]
特征工程及特征组合自动化，一直是推动实用化推荐系统技术演进最主要的方向，没有之一。首先是LR模型，基本是人工特征工程以及人工进行特征组合，简单有效但费时费力；再发展到LR+GBDT高阶特征组合自动化，以及FM模型的二阶特征组合自动化；再往后就是DNN模型的引入，简单纯粹的DNN模型本质上是在FM模型embedding化基础上，添加MLP来进行隐层的非线性自动组合。
典型工作：
Deep& Cross: Deep & Cross Network for Ad Click Predictions
XDeepFM: Combining Explicit and Implicit Feature Interactions for Recommender Systems
3.2 特征抽取器
[图片]
从抽取器的角度来看，最常用的特征抽取器仍包括MLP结构，CNN结构、RNN和Transformer结构，其中MLP结构通常是两层或者三层的隐藏层，但理论表明MLP捕捉特征组合效率低下。而CNN用来捕捉局部特征关联式非常有效的结构，无法捕捉远距离特征关系能力，因此不太适合纯特征输入的推荐模型。
Transformer作为NLP领域最新型的特征抽取器，从工作机制上来说其实非常适合用来做推荐，核心在于Transformer的multi-head self attention机制上。
典型工作：
AutoInt: Automatic Feature Interaction Learning via Self-Attentive Neural Networks
DeepFM: An End-to-End Wide & Deep Learning Framework for CTR Prediction
3.3 强化学习应用
[图片]
强化学习是比较吻合推荐场景建模的，一般而言强化学习有几个关键要素：状态、行为以及回报。在推荐场景下，可以将状态st定义为用户的历史行为物品，而回报可以是用户对推荐物品进行互动的行为价值。由于用户行为空间巨大，制约了很多无法对巨大行为空间建模的RL方法使用，但可以使用典型RL方法：
1. “探索与利用”探索：所谓利用，就是给用户推荐用户当前收益最大的物品，一般推荐系统都是优化这个目标；所以探索，就是随机给用户推荐一些物品，以此探测用户潜在兴趣的东西。
2. 用户兴趣的动态变化：用户兴趣有长期稳定的也有不断变化的，可以通过行为反馈而动态感知兴趣变化。
3. 有利于系统长期收益建模：一般系统短期优化目标比如点击率，长期优化目标例如用户体验，用户活跃留存等。
3.4 多目标优化
推荐系统的多目标优化（点击、互动、时长等多个目标同时优化）不仅是趋势也是现状，尽量做到在优化一个目标的时候，不以另外一个目标为代价。
3.5 长短期兴趣
[图片]
长期兴趣代表用户长久的比较稳当的，而短时兴趣具有不断变化的特点，两者综合可以从稳定性和变化性角度表征用户偏好。
短期兴趣：往往使用用户点击、购买等物品序列来表征，如果序列过长会使用top-K个物品；因为点击序列具备序列性和时序属性，因此比较适合使用transformer建模；
长时兴趣：目前还比较简单，就是用UID特征来表示用户长期兴趣表征。
典型工作：
1. Neural News Recommendation with Long- and Short-term User Representations
2. Sequence-Aware Recommendation with Long-Term and Short-Term Attention Memory Networks
