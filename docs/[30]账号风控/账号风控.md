# 账号风控

## 1. 核心目标
保护平台用户账户安全，识别和处置恶意注册、账户盗用、养号倒卖等行为，维护平台生态和广告主/用户利益。

## 2. 风险类别

### 2.1 恶意注册
- **机器注册**：脚本批量注册，设备/IP集中
- **养号黑产**：注册后不活跃，等待商家收购
- **身份冒用**：盗用真实用户身份信息注册

### 2.2 账户盗用
- **撞库攻击**：利用已泄露密码批量尝试登录
- **钓鱼欺诈**：伪造登录页面骗取账号密码
- **短信/邮箱劫持**：拦截验证码进行登录

### 2.3 账户倒卖
- **养号出售**：批量注册后出售给商家用于刷单/薅羊毛
- **账号租借**：出租账号供他人使用，规避平台管控

### 2.4 恶意行为
- **批量操作**：批量关注、点赞、评论、发帖
- **垃圾内容**：发布广告、诈骗、涉政等违规内容
- **恶意投诉**：对正常商家/用户发起虚假投诉

## 3. 感知&洞察

### 3.1 感知指标
**维度：** 用户、设备、IP、手机号、邮箱、实名信息

**指标：**
- 注册类：注册量、注册转化率、设备聚集度、IP分布
- 活跃类：DAU、MAU、活跃间隔、行为序列
- 画像类：实名率、绑定率、设备标签分布
- 安全类：登录失败率、异常操作率

### 3.2 洞察分析
- **设备指纹**：同一设备注册/登录账号数量，设备标签（模拟器、Root等）
- **IP画像**：IP类型（数据中心/家庭/移动）、IP下账号聚集度
- **行为序列**：正常用户 vs 作弊用户的行为模式差异
- **关系网络**：账号间的关联关系（设备共用、IP共用、联系人关系）

## 4. 识别框架

### 4.1 规则引擎
- 设备黑名单、IP黑名单、手机号黑名单
- 阈值类规则：设备注册账号数 > N、IP注册账号数 > M
- 组合规则：设备类型（模拟器）+ IP类型（数据中心）+ 无实名

### 4.2 机器学习模型
- **有监督模型**：XGBoost / LightGBM 二分类（恶意账号 vs 正常账号）
- **无监督模型**：IsolationForest / DBSCAN 异常账号检测
- **图模型**：Graph Neural Network 账号关联网络挖掘
- **序列模型**：LSTM / Transformer 用户行为序列建模

### 4.3 情报挖掘
- **黑产情报**：监控暗网/黑产论坛，获取泄露数据、黑产工具情报
- **外部数据**：对接第三方风控数据（作弊工具使用情况、欺诈电话标注等）

## 5. 风险标签体系

| 标签 | 含义 | 典型场景 |
|---|---|---|
| 马甲号 | 一人控制多个账号 | 批量操作、刷量 |
| 养号 | 注册后长期不活跃，等待出售 | 账号倒卖 |
| 盗号 | 账号被他人登录使用 | 账号盗用 |
| 虚假注册 | 使用虚假身份信息注册 | 机器注册、冒用注册 |
| 恶意投诉 | 发起虚假投诉敲诈商家 | 商业欺诈 |
| 涉政/涉黄/涉诈 | 发布违规内容 | 内容安全 |

## 6. 处置&评价

### 6.1 处置措施
| 处置方式 | 适用场景 | 效果 |
|---|---|---|
| 注册拦截 | 机器注册、虚假注册 | 从源头阻断 |
| 登录拦截 | 撞库、盗号 | 保护账号安全 |
| 账号冻结 | 确认作弊账号 | 彻底阻断 |
| 功能限制 | 可疑但未确认账号 | 降低损失 |
| 实名降权 | 实名信息异常 | 降低权重 |
| 人工审核 | 复杂case | 精准处置 |

### 6.2 评价指标
- **注册保护率**：拦截恶意注册数 / 总注册数
- **盗号抢救率**：及时拦截的盗号登录 / 总盗号登录
- **误伤率**：正常账号被误处置的比例
- **召回率**：实际作弊账号中被召回的比例
- **人工审核通过率**：进入人工审核的case中通过的比例

## 7. 账号风控 × 其他风控联动

- **账号风控 → 流量风控**：被盗账号参与刷量/虚假流量
- **账号风控 → 补贴风控**：恶意账号参与薅羊毛/套现
- **账号风控 → 内容风控**：批量账号发布垃圾内容
- **账号风控 → 商业风控**：恶意投诉/敲诈商家
