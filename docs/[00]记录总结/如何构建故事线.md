一、为什么每个人的故事线不同？
不同角色的故事线不同
[研发]：整体从目标出发，搞清楚业务逻辑是什么，解释清除怎么做，为什么这么做
1. 目标：是啥，解决了什么问题，带来什么价值？
2. how：怎么做，我们准备怎么做，想做的方式是啥？
3. why：为什么，我们的how为什么会成功，为什么这么做，内在的业务逻辑？

[产品]：更具体，讲清楚为什么要做，怎么怎么做，怎么与大家共建共赢
1. 讲明白未来和价值，吸引大家重视、愿意加入、配合共建
2. 具体上表达怎么做，呈上（夯实前面第一部分的观点）启下（带领大家分工）
3. 让各方能在沙盘里面看到自己的角色和位置（参与什么、承担什么、拿到什么价值）

为什么每个人的故事线不一样
每个人的信息量（上下文）不一样，每个人在大环境中的位置不同；
讲故事的人的目的是不一样，ta希望这个故事能产生一些影响；
最核心的问题是你的位置是什么？你对大环境和小环境的判断是什么？
大环境 = 整个业务逻辑（火星视角），小环境 = 业务相关彼此之间（地球视角）
所以这些事情会决定什么，决定你的目标是什么，你的目标出来之后就是你的故事线

二、厘清三要素：大环境&小环境&目标
讲故事的人和听故事的人存在视角差，要在最开始的时候直面这个问题：厘清大环境、小环境、目标；

[大环境]：受众关心的是什么
大家关心的事情中已达成了共同认知，那些没有达成共同认知；
- 已经达成共识的事情，只需要提示一下；
- 对于没有达成共识的事情，甚至大家不觉得是个事，那么是不是给大家建立认知？是不是以你希望大家认知这件事情的方式，来给大家建立认知？这其实就是目的。

[小环境]：自己看到的什么
公司的关键角色希望从直播业务得到的信息是什么？
找到大家共同认可的事情作为案例，作为整个事情经验的出发点，讲一个大家能接受、大家认为有道理、能解决当前小环境问题的新秩序，然后这个新秩序被充分认同后，大家会自己对号入座；

[目标]：搞清楚关键问题是什么，要达成什么目标
搭建各方都理解、认同的新秩序，让大家会好入座，目的是让大家真正理解，只有这样的秩序才是对的，牵引组织往一个不会产生矛盾，大家彼此都认为OK的方向去发展。

大环境：脱离自己的位置，想清楚业务，受众关心的是什么；
小环境：自己看到的是什么，把自己放进去，想清楚自己是谁，周边是谁；
目标：在小环境下，希望通过这个故事达到什么样的目的，希望对整个环境发生的影响；
有了这三个因素，故事线就出来了：故事线 = 怎么样讲这个故事；

三、故事线框架怎么写
基本要求：
- 故事线300-400字即可，不要面面俱到，要把重点事情讲清楚，不要铺目录；
- 讲清楚重点的东西，用演绎逻辑，不要罗列数据；
- 关注为什么要做xxx，不要讲怎么做（这是细节，不是故事线框架）

找到关键角色的共鸣点
写材料的核心在于，理解关键角色的思维方式和思维路径。你必须让关键角色听懂，芸芸众生可否听懂不重要，要理解关键角色，ta关心什么，找到跟ta的共鸣点，ta才会感兴趣听，ta只有感兴趣才能听懂。不然你的故事就只在讲自己的故事，讲自己的故事是没有人听的。

厘清决策者的决策逻辑
有时候事情较为复杂，或者我们本身不是决策者时，我们需要做的是要理清决策者的决策逻辑，然后去影响他的决策逻辑。比如xx业务，执行层可能不清楚则怎么做，更往上的人在影响决策。

好的故事线，指引不同人做出相同决策
一个好的故事线，不是把结论抛出来，而是给100个人看，100个人都能得出和你一样的结论，这是判断好故事线的核心因素。目的不会写出来，故事线是可以写出来的。
比如，我们不懂xx业务，也没办法教大家怎么做，但我们可以找到一些共识的关键决策链，作为线索抛出来；线索讲清楚，自然就对号入座了，将线索，要用成熟案例来讲。

业务逻辑拆解出弹药库，作为论据使用 
讲清楚事情的过程，其实是在做业务逻辑拆解。要想清楚的是，你要讲清楚的是“国际局势”。
用业务逻辑将“国际局势”，而不是直接将业务逻辑。所以，不应该把重大篇幅放在业务逻辑里面，而是把业务逻辑的关键要素抽离出“国际局势”。不是直接提供具体的解决方案，这两者从内核上是不一样的，所以大家写出来的东西也不一样。
拆解的业务逻辑，不是故事主线，而是弹药库，作为论据使用。论据怎么演绎？条那些事情作为重点？在于你到底要讲什么故事？

四、讲故事小技巧
快速吸引注意力：把大家习以为常、又觉得模糊的事情讲清楚
用很简单的一段阐述，把这个事情讲清楚了，那所有人的注意力一下就进来了。
能不能快速厘清关键要素，用最短的时间把事情讲清楚，清晰的呈现给对方？

提炼共鸣：从大家关心的事情提炼共鸣
提炼共鸣的时候，是在提供输入，一旦你有输入，受众就会产生非常多联想，认为很厉害，ta才会很认真地听你后面的材料；这个需要信息量全面广泛，还要深度思考，这点很准！

表达形式：循循善诱讲故事，慎用图标
在故事线里面，图标不应该作为一个数据结构用来罗列信息，而只应该作为故事的一种表现形式。人的认知方式是一维的，观众的诉求是一眼刚看到一个东西，一张好的图或者表，应该只讲一个故事。
- 表格的优势在于突出对比
- 图的优势在于讲清楚多维关系

五、总结&实践
基于上述方法论和小技巧，确定大环境的需求、小环境的直播视角，确认目标是「厘清线索，奠定共同的话语技巧」，讨论故事线框架并拆解业务逻辑。
