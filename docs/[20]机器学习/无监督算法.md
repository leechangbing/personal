无监督学习（Unsupervised Learning）是指在**没有标签**的情况下，从数据中发现隐藏结构、模式或分布的机器学习方法。其核心目标是**理解数据本身的内在规律**，而非预测输出。

常见的无监督学习任务包括：
- 聚类（Clustering）：将相似样本分组；
- 降维（Dimensionality Reduction）：压缩数据维度，保留关键信息；
- 密度估计（Density Estimation）：建模数据的概率分布；
- 异常检测（Anomaly Detection）：识别罕见或异常样本；
- 关联规则学习（Association Rule Learning）：发现变量间的频繁共现关系。
  
下面系统介绍**常见的无监督算法**，按任务类别组织，涵盖基本思想、原理、优缺点及应用场景。


---

一、聚类算法（Clustering）

1. K-Means
- 思想：将数据划分为 K 个簇，最小化簇内平方误差。
- 优点：简单高效，适合大规模球形簇。
- 缺点：需预设 K；对初始值敏感；无法处理非凸簇。
- 变体：K-Means++（改进初始化）、Mini-Batch K-Means（加速）。
  
2. DBSCAN
- 思想：基于密度连通性发现任意形状簇，识别噪声。
- 优点：无需预设 K；支持任意形状；抗噪声。
- 缺点：对参数 ε 和 MinPts 敏感；高维效果差。
- 改进：HDBSCAN（自动选择密度参数）。
  
3. 层次聚类（Hierarchical Clustering）
- 思想：构建树状聚类结构（凝聚型/分裂型）。
- 优点：无需预设 K；结果可可视化（树状图）。
- 缺点：计算复杂（O(n³)）；不可逆。
  
4. 高斯混合模型（GMM）
- 思想：假设数据由多个高斯分布混合生成，使用 EM 算法估计参数。
- 优点：提供软聚类（隶属概率）；可建模椭球簇。
- 缺点：需预设 K；对初始值敏感。
  
5. 谱聚类（Spectral Clustering）
- 思想：将聚类转化为图分割问题，利用拉普拉斯矩阵特征向量降维后聚类。
- 优点：可发现非凸簇（如环形）。
- 缺点：计算开销大；需预设 K。
  

---

二、降维算法（Dimensionality Reduction）

1. 主成分分析（PCA）
- 思想：投影到方差最大的正交方向，保留全局线性结构。
- 优点：高效、去噪、可解释。
- 缺点：仅适用于线性结构。
  
2. t-SNE
- 思想：保持局部邻域相似性，用于可视化。
- 优点：可视化效果极佳。
- 缺点：不能保留全局结构；无法泛化新样本；计算慢。
  
3. UMAP
- 思想：基于流形假设和拓扑理论，兼顾局部与全局结构。
- 优点：比 t-SNE 更快、保留更多全局信息；支持新样本嵌入。
- 缺点：参数仍需调优。
  
4. 自编码器（Autoencoder）
- 思想：通过神经网络学习低维瓶颈表示，重构输入。
- 优点：非线性、灵活、可处理复杂数据。
- 缺点：需训练；可能过拟合。
  

三、密度估计与生成模型

1. 高斯混合模型（GMM）
- 除用于聚类外，GMM 也是一种**概率密度估计**方法，可生成新样本。
  
2. 核密度估计（KDE, Kernel Density Estimation）
- 思想：在每个数据点放置一个核函数（如高斯核），叠加得到整体密度估计：
\[
\hat{f}(x) = \frac{1}{n h^d} \sum_{i=1}^n K\left( \frac{x - x_i}{h} \right)
\]
- 应用：异常检测（低密度区域为异常）、可视化分布。
  
3. 变分自编码器（VAE）
- 思想：概率生成模型，隐变量服从先验分布（如标准正态），通过变分推断学习。
- 应用：生成新样本、表示学习。
  
4. 生成对抗网络（GAN）
- 虽主要用于生成，但其判别器可学习数据分布特征，属于无监督表示学习。

四、异常检测（Anomaly Detection）

1. 基于统计的方法
- 假设数据服从某分布（如高斯），偏离均值超过阈值的点视为异常。
- 例：Z-score、Grubbs 检验。
  
2. 基于聚类的方法
- 将不属于任何簇或远离簇中心的点视为异常。
- 例：DBSCAN 中的噪声点。
  
3. 基于密度的方法
- 低密度区域的点为异常。
- 例：KDE、LOF（Local Outlier Factor）。
  
4. 孤立森林（Isolation Forest）
- 思想：异常点更容易被随机分割“孤立”出来。
- 优点：高效、适合高维数据。
- 原理：构建随机二叉树，异常点路径更短。
  
5. 一类 SVM（One-Class SVM）
- 思想：学习一个包含大多数正常样本的最小边界，外部为异常。
- 适用：仅提供正常样本的场景（如工业质检）。
  

---

五、关联规则学习（Association Rule Learning）

Apriori 算法
- 目标：发现频繁项集和强关联规则（如“买啤酒的人也买尿布”）。
- 核心概念：
  - 支持度（Support）：项集出现频率；
  - 置信度（Confidence）：规则可靠性；
  - 提升度（Lift）：规则相关性。
- 应用：购物篮分析、推荐系统。
  
FP-Growth（Frequent Pattern Growth）
- 思想：构建 FP 树，避免生成候选项集，效率高于 Apriori。
- 优点：更快、内存更省。

六、其他重要无监督方法

1. 自组织映射（SOM, Self-Organizing Map）
- 思想：神经网络将高维数据映射到低维（通常 2D）网格，保持拓扑结构。
- 应用：可视化、聚类、数据压缩。
  
2. 独立成分分析（ICA, Independent Component Analysis）
- 思想：将混合信号分解为统计独立的源信号（如“鸡尾酒会问题”）。
- 与 PCA 区别：PCA 关注不相关（二阶统计），ICA 关注独立（高阶统计）。
  
3. 非负矩阵分解（NMF, Non-negative Matrix Factorization）
- 思想：将非负矩阵 \( V \approx WH \)，其中 \( W, H \geq 0 \)。
- 应用：文本主题建模（词-文档矩阵）、图像 parts-based 表示。

九、评估无监督学习效果

由于无标签，评估较困难，常用方法包括：
- 内部指标（仅用数据本身）：
  - 聚类：轮廓系数（Silhouette Score）、Calinski-Harabasz 指数；
  - 降维：重构误差（Autoencoder）、最近邻保持率（UMAP/t-SNE）。
- 外部指标（若有真实标签，仅用于验证）：
  - 聚类：ARI、NMI；
  - 异常检测：Precision@K、ROC-AUC。
- 人工评估：可视化检查、领域专家判断。
