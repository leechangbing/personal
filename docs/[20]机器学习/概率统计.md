1. 概率问题
1.1 概率空间
1. 连续抛硬币：两人轮流抛硬币，第一个正面吃苹果，计算先抛的人吃到苹果的概率；-> 计算概率
  1. 解法：P = 1/2 + 1/4*P
  2. 答案：P = 2/3
2. 连续抛硬币：正反则甲胜利，反反则乙胜利，计算甲胜利的概率；-> 计算概率
  1. 解法：P_乙 = 1/2  * 1/2, P_甲  = 1 - P_乙
  2. 答案：P_乙 = 1/4, P_甲 = 3/4
3. 连续抛硬币：正正反则甲胜利，正反反则乙胜利，计算甲乙胜利的概率； -> 计算概率
  1. 解法：P_甲 = 1/2*+1/4*P_甲
  2. 答案：P_甲 = 2/3, P_乙 = 1 - P_甲 = 1/3
4. 生孩子：有一对夫妻生了两个孩子，其中一个女孩，另外一个是男孩的概率；
  1. 空间：男男、男女、女男、女女
  2. 答案：P(男|女) = 1-P(女|女) = 1-1/3 = 2/3
5. 甲乙下棋，单局中甲获胜的概率约为2/3，乙获胜的概率约为1/3，一方比另外一方多赢两局算赢，计算甲获胜的概率;
  1. 解法：P甲=(4/9)/(4/9+1/9) = 4/5, P乙=(1/9)/(4/9+1/9) = 1/5；
6. 有三个小球ABC，选B球时候，主持人说C没有中奖，会换球么；（"三门"问题）
  1. 不换球时候，P_B = 1/3
  2. 换球的时候，P_B = (1/3) / (2/3)  = 1/2
7. 红球概率：有50个红球和50个白球分到两个桶中，问如何分配是的从两个桶中各取一个球，同时为红球的概率最大，并计算最大概率；
  1. 第一种情况：平均分配，P1=P2=1/2，因此P=1/2 * 1/2 = 1/4
  2. 第二种情况：不平均分配，P1>1/2, P2<1/2，且max(p1)=1, max(P2)= 49/99，因此P=1*49/99 = 49/99；
8. 男女比例：若一个家庭没有男孩一直生，直到出生为止，求男女比例（逐步分析）。
  - 解法：第一胎中：男女比例为 1:1；第二胎中：男女比例为 1:1；第三胎中：男女比例为 1:1
  - 答案：因此，总体男女比例为 1:1

1.4 组合概率
1. 随机函数：给定 1~5 的随机函数生成器，生成 1~7 的随机函数（重塑）。
  1. 设 y1 和 y2 是两个独立的 1~5 的随机数。
  2. 构造 y = y1 * 5 + y2，其中 y1, y2 ~ (0, 4)，则 y ~ (0, 24)。
  3. 重新映射 ŷ = y / 4，则 ŷ ~ (0, 6)
2. 以概率 P 生成 1，以概率 (1-P) 生成 0，实现等概率生成 0 和 1
  1. 组合 01，生成概率为 P * (1-P)
  2. 组合 10，生成概率为 (1-P) * P
  3. 由于 P * (1-P) = (1-P) * P，因此可以实现等概率生成 0 和 1
1.5 计算期望
1. 连续抛硬币：连续两次为正则停止，求平均次数；
  1. 解法：E = 1/4*2 + 1/4*(E+2) + 1/2*(E+1)
  2. 答案：E = 6
2. 连续抛硬币：连续K次朝上则停止，计算平均次数；
  1. 公式：E = 1/(2^k)*k + 1/(2^k)*(E+K) + ... + 1/(2^1)(E+1)
  2. 归纳法：
    1. K=1时， E= 1/2*1+1/2*(E+1) => E = 2
    2. K=2时，E=1/4*2 + 1/4*(E+2) + 1/4*(E+1) => E=6
3. 生孩子：直到生男孩为止，计算平均孩子数目；
  1. 解法：E = 1/2*1 + 1/2*(1+E)
  2. 答案：E = 2
4. 抛色子：对于六面色子，直到抛出6为止，求平均次数；
  1. 解法： E = 1/6 * 1 + 5/6*(E+1)
  2. 答案：E = 6
5. 木桶中有M个白球，有放回的涂成红色，求全部涂成红色的平均去求次数
  1. 解法：E = 1 + M/(M-1) + M/(M-2) + ... + M/(M-(M-1)) = M(1/M + 1/(M-1) + ... + 1)
6. 有一把宝剑，升级到一级用一个宝石，有50%的概率会成功，当大于等于5级时失败会掉级，计算从一级到9级的期望宝石数目；
  1. 解法：
    1. 当=1,2,3,4时，E1=E2=E3=E4=1/0.5 = 2
    2. 当i>=5级时候，E_i = 1/2 *1 + 1/2*(1 + E_(i-1) + E_i) = E_(i-2) + 2
    3. 因此，E5 = E4+2 = 4, E6 = E5+2 = 6,... E9=12；

2.1 蓄水池采样
1. 蓄水池采样：等权重从无限长的数据流中，随机抽取 k 个数据，如何实现；
  1. 假设共有n个数据，其中n为无限大；
  2. 抽样方案：当n<=k的时候，全部保留进入采样池；当n>k的时候，先按照p=k/n的概率判断是否保留当前数据，然后再按照1/k的概率从采样池中删除一个；
  3. 证明采样方案完全随机：
    1. 当n<=k时候，p=1
    2. 当n>k时候，p_old = k/(n-1)，p_new = p_old * ((n-k)/n + k/n * (k-1)/k) = p_old * (n-1)/n = k/n
  4. 变形题目：带权重从数据流中，抽取 k 个数据；
