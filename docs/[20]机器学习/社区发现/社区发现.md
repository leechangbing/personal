1. 整体介绍
社区挖掘（Community Detection）是复杂网络分析中的核心任务之一，旨在发现网络中具有紧密内部连接、稀疏外部连接的节点子集（即社区）。根据不同的划分标准，社区挖掘可分为多种类型。下面将系统地介绍常见的社区挖掘类型、每种类型中的代表性算法，并详细阐述其基本思想、数学定义和算法过程。

- 社区挖掘的主要类型：
  - 非重叠社区检测（Disjoint / Non-overlapping Communities）
    - 每个节点仅属于一个社区。
    - 适用于结构清晰、边界分明的网络。
- 重叠社区检测（Overlapping Communities）
  - 节点可同时属于多个社区。
  - 更符合现实场景（如一个人可同时属于家庭、公司、兴趣小组等）。
- 层次化社区检测（Hierarchical Communities）
  - 社区结构具有层次性（如树状结构），大社区可进一步划分为子社区。
  - 可分为凝聚型（自底向上）和分裂型（自顶向下）。
- 动态社区检测（Dynamic Communities）
  - 针对随时间演化的网络，追踪社区结构的变化。
  - 关注社区的出现、消失、合并、分裂等行为。
- 有向/加权/符号网络中的社区检测
  - 考虑边的方向、权重或正负关系（如信任/不信任）。
  - 需要对传统算法进行扩展。

1.2 基础概念
- 模块度（Modularity） 是最常用的社区质量评估指标，但存在分辨率限制（Resolution Limit）问题。
- 近年来，图神经网络（GNN） 也被用于社区检测（如ComE、DAEGC），但通常需要标签或辅助信息。
- 实际应用中，常结合多种算法或使用集成方法提升鲁棒性。

1.3 使用方式
- 使用场景
  - 大规模网络：优先考虑 Louvain、Leiden 或 LPA。
  - 需要重叠社区：考虑 CPM、OSLOM 或 NMF。
  - 有向/加权网络：Infomap 表现优异。
  - 理论可解释性要求高：使用 SBM。
  - 实时性要求高：LPA 或 Leiden。

2. 常用算法
2.1 非重叠社区检测
Girvan–Newman算法
- 类型：分裂型层次化算法，也可用于非重叠社区。
- 基本思想：基于边介数（edge betweenness）逐步移除连接不同社区的“桥梁”边。
- 数学定义：
  - 边介数：网络中所有最短路径中经过该边的路径数量。
  - 社区划分目标：最大化模块度（Modularity）。
- 算法过程：
  1. 计算所有边的介数；
  2. 移除介数最高的边；
  3. 重复步骤1–2，直到所有边被移除；
  4. 在移除过程中记录模块度变化，选择模块度最大时的划分作为最终结果。
- 优点：原理清晰，效果好。
- 缺点：计算复杂度高（O(m²n)），不适合大规模网络。

Louvain算法
- 类型：基于模块度优化的贪心算法。
- 基本思想：通过局部移动节点以最大化模块度，迭代优化。
- 模块度定义（Newman 定义） ：
- Q=12m∑i,j[Aij−kikj2m]δ(ci,cj)
- 其中：
  - Aij：邻接矩阵元素；
  - ki：节点 i 的度；
  - m：总边数；
  - δ(ci,cj)=1 若 i 和 j 属于同一社区，否则为 0。
- 算法过程（两阶段迭代） ： 阶段1（局部优化） ：
  - 初始化每个节点为一个社区；
  - 遍历所有节点，将其移至邻居社区中使模块度增益最大的那个（若增益为正）；
  - 重复直到模块度不再增加。
- 阶段2（网络聚合） ：
  - 将每个社区收缩为一个超节点；
  - 超节点之间的边权重为原社区间所有边权重之和；
  - 在新网络上重复阶段1。
  - 重复两阶段，直到模块度收敛。
- 优点：高效（近线性时间），适合大规模网络。
- 缺点：可能陷入局部最优；分辨率限制（无法检测小社区）。
2.2 重叠社区检测
CPM
- 基本思想：基于 k-团（k-clique）的连通性定义重叠社区。
- 数学定义：
  - k-团：k个节点两两相连的完全子图。
  - 两个k-团若共享k−1个节点，则称它们是“相邻”的。
  - 一个社区定义为通过相邻关系连接的所有k-团的并集。
- 算法过程：
  1. 找出网络中所有k-团（通常k=3或4）；
  2. 构建k-团邻接图；
  3. 找出该图中的连通分量；
  4. 每个连通分量对应的节点集合即为一个重叠社区。
- 优点：自然支持重叠，理论基础强。
- 缺点：对k敏感；在稀疏网络中难以找到足够k-团。
BigClam 
- 基本思想：基于概率生成模型，每个节点对每个社区有一个“隶属强度”。
- 数学模型：
  - 设有 C 个社区，节点 i 对社区 F 的隶属度为 FiF∈[0,1]；
  - 节点 i 和 j 之间存在边的概率为：P(Aij=1)=1−exp⁡(−∑F=1CFiFFjF)
  - 目标：最大化观测网络的对数似然函数。
- 算法过程：
  - 使用梯度上升或坐标上升法优化隶属矩阵 F；
  - 可结合社区数量估计（如通过交叉验证）。
- 优点：可扩展性强，适合大规模网络；输出软隶属度。
- 缺点：需预设社区数量；优化过程复杂。
2.3 层次化社区检测
层次聚类
- 基本思想：基于节点相似性（如Jaccard系数、共同邻居等）进行聚类。
- 类型：
  - 凝聚型（Agglomerative）：自底向上，逐步合并最相似社区；
  - 分裂型（Divisive）：自顶向下，逐步分裂社区（如GN算法）。
- 算法过程（凝聚型） ：
  1. 每个节点为一个簇；
  2. 计算所有簇对之间的相似度；
  3. 合并最相似的两个簇；
  4. 更新相似度矩阵；
  5. 重复直到只剩一个簇。
- 输出：树状图（dendrogram），可按阈值切割得到具体划分。

Infomap 算法
- 基本思想：基于信息论，最小化描述随机游走路径所需的平均码长。
- 数学基础：
  - 使用两层编码：社区层 + 节点层；
  - 目标函数：最小化 Map Equation：L(M)=q↷H(Q)+∑i=1mp↻iH(Pi)其中：
    - q↷：离开社区的概率；
    - p↻i：在社区 i 内停留的概率；
    - H 为香农熵。
- 算法过程：
  - 使用贪心搜索或模拟退火优化社区划分以最小化 L(M)；
  - 支持非重叠和层次化结构。
- 优点：理论优美，适用于有向/加权网络。
- 缺点：对参数敏感；难以直接处理重叠社区。

2.4 标签传播
社区发现之标签传播算法（LPA）
标签传播算法（Label Propagation Algorithm， LPA）初探 - 郑瀚 Andrew - 博客园
Label Propagation Algorithm，也称为标签传播算法（LPA），是一个在图中快速发现社群的算法，由 Raghavan 在 2007 年于Near linear time algorithm to detect community structures in large-scale networks提出。在 LPA 算法中，节点的标签完全由它的直接邻居节点决定。标签传播算法是一种基于标签传播的局部社区发现算法，基本思想是节点的标签（community）依赖其邻居接地那的标签信息，影响程度由节点相似度决定，并通过传播迭代更新达到稳定。
算法步骤
s1: 初始化：初始化网络中所有节点的标签，对于给定节点 x，$$C_x(0)=x$$
s2: 设置$$t=1$$
s3: 以随机顺序排列网络中的节点，并将其设置为$$x$$
s4: 对于特定顺序选择的每个$$x\in{X}$$，让$$C_x(t)=f(C_{x_{i1}}(t),...,C_{x_{im}}(t),C_{x_{i(m+1)}}(t-1),...,C_{x_{ik}}(t-1))$$，$$f$$这里返回相邻标签中出现频率最高的标签，如果有多个最高频率的标签，就随机选择一个标签
s5: 如果每个节点都有其邻居节点中数量最多的标签，则停止算法，否则，设置 t=t+1 并转到 s3
这是一个迭代的过程且不保证收敛，大体思路是每个节点都把自己标签设置为邻居节点中频率最高的标签，当完全一致后，算法结束。对于这个算法，计算复杂度$$O(KE)$$，其中$$K$$是迭代次数，$$E$$是边的数量，按照历史经验迭代次数大概是 5 次的时候就能近似收敛。





3. 与无监督算法的区别
社区发现（Community Detection）算法与无监督学习（Unsupervised Learning）算法在目标和方法上高度相关，但二者在问题定义、输入形式、理论背景和应用场景 上存在重要区别。下面从联系 与区别 两个维度进行系统阐述。

3.1 核心联系
社区发现是无监督学习的特例

✅ 1. 都属于“无标签学习”
- 社区发现**不需要预先知道节点所属社区**（即无标签）；
- 无监督学习的典型任务（如聚类、降维）也**不依赖标签**；
- 二者都试图从数据中**自动发现隐藏结构**。
  
✅ 2. 目标高度一致
- 社区发现：将网络中的节点划分为若干子群，使得**群内连接紧密、群间连接稀疏**；
- 聚类（无监督核心任务）：将数据点划分为若干簇，使得**簇内相似性高、簇间相似性低**；
- 本质上都是“**内聚外疏**”的分组问题。
  
✅ 3. 部分算法可通用或转化
- 谱聚类（Spectral Clustering） 既是经典聚类算法，也是社区发现的基础方法（通过图拉普拉斯矩阵）；
- 若将图节点通过**嵌入（Embedding）** 映射为向量（如 Node2Vec、DeepWalk），则可用 K-Means、DBSCAN 等聚类算法进行社区发现；
- 模块度（Modularity） 优化思想与聚类中的“类内紧密度”目标相通。
  
🌰 举例：  
社区发现流程常为：  
图 → 节点嵌入（无监督表示学习） → 聚类（无监督分组） → 社区划分  
此时，社区发现 = 无监督表示学习 + 无监督聚类。

3.2.1 输入范式不同：图 vs 特征向量
- 社区发现的输入是**关系型数据**（谁认识谁），即使节点无任何属性，也能发现社区；
- 无监督聚类的输入是**属性型数据**（每个对象有特征描述），若无特征则无法计算相似性。
  
🔍 举例：  
- 一个社交网络只有“用户A关注用户B”的边，无年龄、性别等信息 → **只能用社区发现**；  
- 一组用户有“年龄、收入、消费频次” → **可用 K-Means 聚类**，但无法直接用 Louvain。

3.2.2 相似性定义不同
- 社区发现中的“相似”是**结构性的**：  
  - 两个节点可能无直接边，但因大量共同邻居而属于同一社区；
  - 使用指标如 Jaccard 系数、Adamic-Adar、随机游走距离等。
- 无监督聚类中的“相似”是**度量空间中的距离**：  
  - 直接计算特征向量间的欧氏距离、余弦距离等。
    
3.2.3 算法设计哲学不同
- 社区发现算法常基于：
  - 模块度优化（Louvain）；
  - 信息流最小化（Infomap）；
  - 团渗透（CPM）；
  - 边介数（Girvan-Newman）。
- 无监督聚类算法常基于：
  - 距离最小化（K-Means）；
  - 密度连通（DBSCAN）；
  - 概率生成（GMM）；
  - 流形保持（t-SNE, UMAP）。
    
3.3 整体总结
3.3.1 边界模糊：图表示学习架起桥梁
随着图神经网络(GNN)和图嵌入(Graph Embedding) 的发展，社区发现与无监督学习的界限日益模糊；现代社区发现典型流程：
1. 图 → 节点嵌入（无监督表示学习）  
  - 方法：DeepWalk, Node2Vec, GraphSAGE, VGAE
2. 嵌入向量 → 聚类（无监督分组）  
  - 方法：K-Means, GMM, DBSCAN
3. 输出社区划分
此时，社区发现被转化为一个无监督聚类问题 ，但前提是先通过无监督方法将图结构“翻译”为特征向量。
3.3.2 一句话概括
社区发现是无监督学习在图结构数据上的具体应用。  它继承了无监督学习“发现隐藏结构”的目标，但专门针对网络拓扑设计 ，强调连接关系而非特征相似性 。

4. 与聚类算法 的区别
社区发现（Community Detection）算法与聚类（Clustering）算法在目标上高度相似——都是将对象分组，使得组内相似性高、组间相似性低，但它们在问题背景、输入形式、理论基础和应用场景上存在显著差异。下面从联系与区别两个维度系统阐述：
4.1 核心联系
- 目标一致：两者都追求“内聚外疏”的划分：
  - 聚类：组内样本特征相似，组间差异大；
  - 社区发现：社区内节点连接紧密，社区间连接稀疏。
- 部分算法可通用：某些算法在形式上可互相转化：
  - 谱聚类（Spectral Clustering） 既可用于传统聚类，也可用于社区发现（通过图拉普拉斯矩阵）；
  - DBSCAN、K-Means 可用于社区发现，前提是节点有嵌入向量（如通过 Node2Vec 得到的低维表示）；
  - 层次聚类 可直接用于基于节点相似性（如Jaccard系数）的社区划分。
- 评估指标部分重叠
  - 模块度（Modularity）虽为社区发现专用，但其思想类似于聚类中的“类内紧密度”；
  - 聚类中的轮廓系数（Silhouette Score）、Calinski-Harabasz 指数等也可用于评估嵌入空间中的社区质量。

4.3 关键差异详解
- 输入本质不同
  - 聚类：输入是 n×d 的特征矩阵 X，每一行是一个对象的特征描述。
  - 社区发现：输入是 n×n 的邻接矩阵 A，描述节点间的连接关系。
  - 举例：
    - 聚类：对1000个用户按“年龄、消费金额、登录频率”聚类；
    - 社区发现：对1000个用户按“谁关注了谁”构建图，发现兴趣圈子。
- 相似性来源不同
  - 聚类中的相似性是显式的（由特征计算）；
  - 社区发现中的相似性是隐式的、结构性的（即使两个节点无直接边，也可能因共同邻居而属于同一社区）。
- 图嵌入架起桥梁：现代图表示学习（Graph Representation Learning）模糊了二者界限：
  - 先用 Node2Vec / GraphSAGE / GCN 将节点映射为低维向量；
  - 再用 K-Means / DBSCAN 对向量聚类；
  - 聚类结果即为社区划分。
此时，社区发现 = 图嵌入 + 聚类，聚类算法成为社区发现的“后端工具”。

4.5 总结：一句话概括
聚类是“基于特征的分组”，社区发现是“基于关系的分组” 。二者目标相通，但输入范式不同；在图嵌入技术出现后，聚类算法常被用作社区发现的实现手段，但社区发现更强调网络拓扑结构的利用。

附：如何选择？
- 如果你有节点特征 + 图结构 → 可结合两者（如 GNN + 聚类）；
- 如果只有图结构（无特征） → 优先使用 Louvain、Infomap 等经典社区发现算法；
- 如果只有特征（无图） → 使用 K-Means、DBSCAN 等聚类算法；
- 如果想发现重叠社区 → 选择 CPM、BigClam，而非传统聚类。
