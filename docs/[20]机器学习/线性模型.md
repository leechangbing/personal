1. 基础定义
概率（probability）：已知参数预测结果，其表达为$$P(x|\theta)$$；
似然（likelihood）：是已知结果预测参数，其表达为$$P(\theta|x)$$；
极大似然估计（maximum likelihood estimate， MLE）：极大似然估计，使观测结果发生概率最大的参数；
最大后验概率（maximum posterior probability， MAP）：最大后验概率，在 MLE 的基础上，参数存在先验分布；


2. 极大似然估计
2.1 核心思想
在已知观测数据的前提下，选择使得这些数据出现概率最大的模型参数。假设数据是由某个参数为 θ 的概率模型生成的，那么希望找到一个 θ̂，使得观测数据在该参数下的“似然”最大。

2.2 数学定义
设观测数据为$${D} = \{x_1, x_2, ..., x_n\} $$，假设这些数据独立同分布（i.i.d.），来自某个概率分布$$p(x|\theta) $$，其中$$\theta$$是待估计的参数。
似然函数定义为：
$${L}(\theta; {D}) = p({D}|\theta) = \prod_{i=1}^n p(x_i|\theta)$$
极大似然估计的目标是：
$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} {L}(\theta; {D}) = \arg\max_{\theta} \prod_{i=1}^n p(x_i|\theta)$$
为便于计算，通常取对数（对数似然）：
$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \log {L}(\theta; {D}) = \arg\max_{\theta} \sum_{i=1}^n \log p(x_i|\theta)$$
主要特点：频率学派方法，不假设参数有先验分布。只依赖于观测数据。当样本量足够大时，MLE 具有良好的统计性质（一致性、渐近正态性、有效性），但容易过拟合，尤其在小样本或高维参数情况下。

2.3 离散分布
伯努利实验：假设单次成功概率为$$p$$，进行$$n$$次实验成功$$t$$次，求似然函数的最大值；
$$L(p)=f_D(H=t, T=n-t | p)=C_{n}^t\cdot p^t\cdot (1-p)^{n-t}$$
两边同时对$$p$$求导数，并使其为零：
$$\begin{aligned} 0 &\propto tp^{t-1}(1-p)^{n-t}-(n-t)p^t(1-p)^{n-t-1}\\ &=p^{t-1}(1-p)^{n-t-1}(t(1-p)-(n-t))\\ &=p^{t-1}(1-p)^{n-t-1}(tp-n) \end{aligned}$$
因此，最大似然估计值：$$\hat{p}=\frac{t}{n}$$

2.4 连续分布
最常见的连续概率分布是正态分布，其概率密度函数如下：
$$f(x|u, \sigma^2)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-u)^2}{\sigma^2}}$$
已知$$n$$个正态随机变量的采样点，求$$(u,\sigma^2)$$使得观测到这些采样点的可能性最大，其$$n$$个正态随机变量的联合概率密度函数（假设服从独立同分布）为：
$$\begin{aligned} f(x_1,...,x_n|u,\sigma^2) =\Big(\frac{1}{2\sigma^2}\Big)^{\frac n2}e^{-\frac{\sum(x_i-u)^2}{2\sigma^2}} =\Big(\frac1{2\sigma^2}\Big)^{\frac{n}{2}}\exp^{-\frac{\sum(x_i-\=x)^2+n(\=x-u)^2}{2\sigma ^2}} \end{aligned}$$
最大化一个似然函数等价于最大化它的自然对数，因为log是一个连续且在似然函数的值域内严格递增的上凹函数
$$\begin{aligned} 0&=\frac{\partial}{\partial u}\log\Bigg(\bigg(\frac1{2\sigma^2}\bigg)^{\frac{n}{2}}e^{-\frac{\sum(x_i-\=x)^2-n(\=x-u)^2}{2\sigma^2}} \Bigg)\\ &=0-\frac{-2n(\=x-u)}{2\sigma^2} \end{aligned}$$
这个方程的解是$$\textstyle\hat{u}=\=x=\sum x_i/n$$
$$\begin{aligned} 0&=\frac{\partial}{\partial \sigma}\log\Bigg(\bigg(\frac1{2\sigma^2}\bigg)^\frac{n}{2}e^{-\frac{\sum(x_i-\=x)^2+n(\=x-u)^2}{2\sigma^2}} \Bigg)\\ &=\frac{\partial}{\partial \sigma}\bigg(\frac{n}{2}\log\Big(\frac1{2\sigma^2}\Big)-\frac{\sum(x_i-\=x)^2+n(\=x-u)^2}{2\sigma^2}\bigg)\\ &=-\frac{\sigma}{n}+\frac{\sum(x_i-\=x)^2+n(\=x-u)^2}{\sigma^3} \end{aligned}$$
这个方程的解是$$\textstyle\hat\sigma^2=\sum(x_i-\=x)^2/n$$
因此，关于$$\textstyle \theta=(u,\sigma^2)$$的最大似然估计是：$$\textstyle \hat\theta=(\hat u, \hat \sigma^2)=(\=x, \sum(x_i-\=x)^2/n)$$

2.5 主要特点
- 频率学派方法：不假设参数有先验分布。
- 只依赖于观测数据。
- 当样本量足够大时，MLE 具有良好的统计性质（一致性、渐近正态性、有效性）。
- 容易过拟合，尤其在小样本或高维参数情况下。
3. 最大后验概率
3.1 核心思想
MAP 是贝叶斯学派的方法。它在 MLE 的基础上引入了对参数的先验信念（先验分布）。目标是找到在给定数据下，参数的后验概率最大的值。即：不仅考虑数据出现的可能性，还考虑参数本身的“合理性”（由先验体现）。
3.2 数学定义
根据贝叶斯定理，参数$$\theta$$的后验分布为：
$$p(\theta|{D}) = \frac{p({D}|\theta) p(\theta)}{p({D})}$$
其中：
- $$p({D}|\theta) $$ 是似然（与 MLE 相同），
- $$p(\theta)$$是参数的先验分布，
- $$p({D})$$ 是证据（与 θ 无关，可视为常数）
MAP 估计为：
$$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} p(\theta|\mathcal{D}) = \arg\max_{\theta} p(\mathcal{D}|\theta) p(\theta)$$
取对数形式：
$$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} \left[ \sum_{i=1}^n \log p(x_i|\theta) + \log p(\theta) \right]$$

3.3 主要特点
- 引入了先验信息 ，可防止过拟合（尤其在数据少时）。
- 当先验为均匀分布，即$$ p(\theta) = \text{const}$$时，MAP 退化为 MLE。
- 本质上是带正则化的 MLE：例如，高斯先验对应 L2 正则，拉普拉斯先验对应 L1 正则。
- 仍是一个点估计 （只给出一个最优参数值），不同于完整的贝叶斯推断（给出后验分布）。

3.4 二者对比总结
- MLE：只看数据，找最可能生成这些数据的参数。
- MAP：结合数据和先验知识，找最“合理”的参数。
- MAP 可视为带先验的 MLE ，在机器学习中常体现为正则化 。
- 若想获得参数的不确定性（而不仅是点估计），应使用完整贝叶斯推断 （如计算后验分布、使用 MCMC 等）。

4. 线性回归
1. 输出函数：
$$y'=f(x)=z=\sum\nolimits_{k}{w_k}\cdot{x_k} + b$$
2. 损失函数：
$$L(Y,f(X))=\frac1{2n}\sum\nolimits_i(f(x_i)-y_i)^2=\frac1{2n}\sum\nolimits_i(y_i'-y_i)^2=\frac1{2n}\sum(z_i-y_i)^2$$
3. 梯度函数
$$\frac{\partial{L}}{\partial{w_k}}=\frac1n\sum(z_i-y_i)z'(x_i)=\frac1n\sum(y'_i-y_i)x_{ik}$$
$$\frac{\partial L}{\partial b}=\frac1n\sum(y'_i-y_i)$$

5. 逻辑回归
1. 输出函数：
  $$f(x)=\sigma(z), z=\sum\nolimits_k(w_k\cdot x_k+b)$$
2. 损失函数：
  $$L(Y,f(X))=-\frac{1}{n}\sum\nolimits_i{y_i\cdot log(\sigma(z_i))}$$
3. 梯度函数：
$$\begin{aligned} \frac{\partial L}{\partial w_k} &=-\frac{1}{n}\sum\nolimits_i{{y_i\cdot\frac1{\sigma(z_i)}\cdot{\sigma'(z_i)}\cdot z(x_i)'}}\\ &=-\frac1n\sum\nolimits_i{y_i}\cdot(1-\sigma(z_i))\cdot{x_{ik}}\\ &=-\frac1n\sum\nolimits_iy_i\cdot(1-f(x_i))\cdot{x_{ik}} \\ &=\frac1n\sum\nolimits_iy_i\cdot(f(x_i)-y_i)\cdot{x_{ik}}\\ &=\frac1n\sum\nolimits_iy_i\cdot(y'_i-y_i)\cdot{x_{ik}} \end{aligned}$$
$$\begin{aligned} \frac{\partial L}{\partial b} &=-\frac1n\sum\nolimits_i y_i\cdot\frac{1}{\sigma(z_i)}\sigma'(z_i)\cdot z'(b_i)\\ &=-\frac1n\sum\nolimits_iy_i\cdot(1-\sigma(z_i))\\ &=-\frac1n\sum\nolimits_i y_i\cdot(1-f(x_i))\\ &=\frac1n\sum\nolimits_i y_i\cdot(f(x_i)-y_i)\\ &=\frac1n\sum\nolimits_iy_i\cdot(y'_i-y_i) \end{aligned}$$
