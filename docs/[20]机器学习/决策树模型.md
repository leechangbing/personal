1. 基础概念
决策树（Decision Tree）、随机森林（Random Forest）和提升树（Boosting Tree，如 GBDT、XGBoost、LightGBM）构成了机器学习中从单模型 → 并行集成 → 串行集成 的完整演进路径。
- 决策树(Decision Tree)：一种树形结构的监督学习模型，通过递归地对特征进行划分，将样本分配到叶节点，每个叶节点对应一个预测结果（分类或回归），划分标准分为：
  - 分类任务：ID3->信息增益，C4.5->信息增益率，CART->基尼指数
  - 回归任务：最小化均方误差
- 随机森林(Random Forest)：由多个决策树组成的集成模型，采用 Bagging+随机特征选择 策略，核心思想是通过降低方差提升泛化能力，训练过程
  - 从原始数据集中有放回地抽取多个 Bootstrap 子样本；
  - 对每个子样本训练一棵决策树，且在每次节点分裂时，仅从随机选取的特征子集中选择最优划分特征；
  - 最终预测结果通过多数投票（分类）或 平均（回归） 得到。
- 提升树(Boosting Tree)：一类串行集成方法，通过迭代训练多个弱学习器（通常是浅层决策树），每轮关注前一轮预测错误的样本，最终加权组合所有弱学习器；核心思想是通过降低偏差提升模型性能，代表算法有：
  - AdaBoost：调整样本权重，使后续模型更关注错分样本；
  - Gradient Boosting（GBDT）：通过拟合负梯度（即残差）逐步优化损失函数；
  - XGBoost / LightGBM / CatBoost：GBDT 的高效工程实现，引入正则化、近似分裂、类别特征处理等优化。
- 三者联系：
  - 基础模型相同：三者都以决策树作为基本的学习器(基学习器)。决策树是一种树形结构模型，通过递归地对特征进行划分，实现对样本的分类或回归。
  - 集成学习思想：随机森林和提升树都属于集成学习(Ensemble Learning)方法，即通过组合多个弱学习器（通常是浅层决策树）来构建一个更强的模型。随机森林采用Bagging策略，通过投票或者平均方式降低方差提升泛化能力；而提升树采用Boosting策略，通过降低偏差提升性能。

2. 决策树
2.1 特征选择
- 熵（Entropy）
  - $$H(X) = -\sum_{i=1}^{n} p_i \log p_i, \quad 0 \le H(p) \le \log n$$
- 信息增益（Information Gain, ID3）
  - $$g(D, A) = H(D) - H(D|A)$$
  - $$H(D) = -\sum_{k=1}^K \frac{|C_k|}{|D|} \log_2 \frac{|C_k|}{|D|}$$
  - $$H(D|A) = \sum_{i=1}^{n} \frac{|D_i|}{|D|} H(D_i) = \sum_{i=1}^{n} \frac{|D_i|}{|D|} \sum_{k=1}^{K} \frac{|D_{ik}|}{|D_i|} \log_2 \frac{|D_{ik}|}{|D_i|}$$
- 信息增益率（Gain Ratio, C4.5）
  - $$g_R(D, A) = \frac{g(D, A)}{H_A(D)}, \quad H_A(D) = -\sum_{i=1}^{n} \frac{|D_i|}{|D|} \log_2 \frac{|D_i|}{|D|}$$
- 基尼指数（Gini Index, CART）
  - $$\text{Gini}(p) = 1 - \sum_{k=1}^{K} p_k^2 = \sum_{k=1}^{K} p_k(1 - p_k)$$
  - $$\text{Gini}(D, A) = \frac{|D_1|}{|D|} \text{Gini}(D_1) + \frac{|D_2|}{|D|} \text{Gini}(D_2)$$
2.2 ID3 算法
输入：训练集D，特征集 A，阈值 $$\epsilon$$  
输出：决策树T
特点：信息增益最大
缺点：偏好取值多的特征；不能处理连续值；易过拟合；
  算法流程：
  - S1：单节点树判断
    - 若D中所有样本属于同一类$$C_k$$，则T为单节点树，标记为$$C_k$$；
    - 若$$A = \varnothing$$，则T为单节点树，标记为D中样本最多的类；
  - S2：计算信息增益
    - 计算A中各特征的信息增益$$g(D, A)$$，选择最大的$$g(D, A)$$；
    - 如果$$g(D, A_g) < \epsilon$$，则T为单节点树，标记为多数类；
  - S3：递归调用
    - 按 $$A_g = a_i$$ 将 $$D$$ 划分为非空子集$$D_t$$，对每个 $$D_t$$ 构建子节点；
    - 对每个子节点，以 $$D_i$$ 为训练集、$$A - \{A_g\}$$为特征集，递归调用 ；
2.3 C4.5 算法
输入：训练集D，特征集 A，阈值 $$\epsilon$$  
输出：决策树T
特点：信息增益率最大
改进：缓解 ID3 对多值特征的偏好；支持连续特征离散化；支持剪枝；
  算法流程：
  - S1：单节点树判断
    - 若D中所有样本属于同一类$$C_k$$，则T为单节点树，标记为$$C_k$$；
    - 若$$A = \varnothing$$，则T为单节点树，标记为D中样本最多的类；
  - S2：计算信息增益率
    - 计算A中各特征的信息增益$$g_R(D, A)$$，选择最大的$$g_R(D, A)$$；
    - 如果$$g(D, A_g) < \epsilon$$，则T为单节点树，标记为多数类；
  - S3：递归调用
    - 按 $$A_g = a_i$$ 将 $$D$$ 划分为非空子集$$D_t$$，对每个 $$D_t$$ 构建子节点；
    - 对每个子节点，以 $$D_i$$ 为训练集、$$A - \{A_g\}$$为特征集，递归调用  ；
2.4 CART 算法
CART 是二叉树 ，支持分类与回归。
  - 模型形式：CART对应着特征空间的一种划分方式，以及子空间的输出值，假设已将特征空间划分为M个子空间$$R_m$$，并且在每个子空间上有一个固定的输出值$$c_m$$，于是可以表示为：
  $$f(x) = \sum_{m=1}^{M} c_m I(x \in R_m)$$
  - 最优值输出：当特征空间划分方式确定时，
    - 回归树：可以用平方误差来表示回归树的预测误差，采用最小化平方误差原则求解每个子空间的最优输出值，易知子空间$$R_m$$上$$c_m$$的最优值，是$$R_m$$上的所有输入实例$$x_i$$对应输出$$y_i$$的均值，即：
  $$\hat{c}_m=ave(y_i|x_i\in R_m)$$
    - 分类树：可以用基尼指数来表示分类树的预测误差，采用最小化平方误差原则求解每个子空间的最优输出值，易知子空间$$R_m$$上$$c_m$$的最优值，是$$R_m$$上的所有输入实例$$x_i$$对应输出$$y_i$$最大类别，即：
  $$\hat{c}_m=max(p(y_i)|x_i\in R_m)$$
  - 算法流程：根据训练数据集，从根节点开始递归地对每个结点进行以下操作，构建二叉决策树；
    - 对当前节点数据集$$D$$，遍历所有特征$$A$$及其所有可能切分点$$a$$；
    - 计算每个 $$(A, a)$$ 对应的基尼指数（分类）或 MSE（回归）；
    - 选择使指标最小的 $$(A^*, a^*)$$ 作为最优划分(最优切分特征和最优切分点)；
    - 递归处理左右子节点，直至满足停止条件（如节点样本数 < 阈值、纯度足够高等）。

3. 提升树
- Boost  Tree: 提升树
- 拟合目标：预测值和真实值之间的差值，即残差；
提升决策树模型可以表示为决策树的加法模型，其中$$\Theta_m$$表示决策树的参数，$$M$$表示决策树的个数。
$$f_M(x)=\sum_{m=1}^{M}T(x, \Theta_m)$$
提升树算法采用前向分布算法，首先确定$$f_0(x)=0$$，第$$m$$步的模型是：
$$f_m(x)=f_{m-1}(x)+T(x,\Theta)$$
通过经验风险极小化确定下一颗决策树的参数$$\theta_m$$：
$$\hat\Theta_m=\argmin\sum_{i=1}^{N}L({y_i, f_{m-1}(x_i)+T(x_i,\Theta_m)})$$
当采用平方误差损失函数时：
$$L(y,f(x))=(y-f(x))^2$$
损失函数变为：其中$$r=y-f_{m-1}(x)$$
$$L(y, f_{m-1}(x)+T(x, \Theta_m))=[y-f_{m-1}(x)-T(x, \Theta_m)]^2=[r-T(x, \Theta_m)]^2$$
3.1 GBDT
- GBDT：Gradient Boosting Decision Tree，梯度提升决策树
- 核心思想：对任意可微损失函数 ，用负梯度作为拟合目标
当损失函数是平方损失函数时，通过拟合残差就即可优化；但对于一般的损失函数，利用损失函数的负梯度作为当前模型的目标值；
$$-\Big[\frac{\partial L(y, f(x_i))}{\partial f(x_i)} \Big]_{f(x)=f_{m-1}(x)}$$

例子：对于回归问题通过提升树算法逼近残差，拟合一颗回归树
- 输入&输出
  - 输入：训练数据集$$T=\{(x_1,y_1), (x_2,y_2),...,(x_N, y_N)\}$$，损失函数$$L(y,f(x))$$；
  - 输出：回归树$$\hat{f}(x)$$；
- 算法流程
  - 初始化：
$$f_0(x)=\argmin_c \sum_{i=1}^{N}L(y_i,c)$$
  - 对$$\textstyle m=1,2,...,M$$，计算输入样本的拟合目标值：
$$r_{mi}=-\Big[\frac{\partial L(y_i,f(x_i))}{\partial f(x_i)}\Big]_{f(x)=f_{m-1}(x)}$$
  - 对$$r_{mi}$$拟合一个回归树，得到低 m 棵树的叶节点区域$$R_{mj}$$，对$$j=1,2,...,J$$计算：
$$c_{mj}=\argmin_c \sum_{x_i\in R_{mj}}L(y_i, f_{m-1}(x_i)+c)$$
  - 更新$$\textstyle f_m(x)=f_{m-1}(x)+\sum_{j=1}^Jc_{mj}I(x\in R_{mj})$$，得到回归树：
$$\hat{f}(x)=f_M(x)=\sum_{m=1}^M\sum_{j=1}^Jc_{mj}I(x\in R_{mj})$$
3.2 XGBoost
XGBoost：eXtreme Gradient Boosting是梯度提升决策树（Gradient Boosting Decision Tree, GBDT）的一种高效、可扩展、工程优化的实现，由陈天奇（Tianqi Chen）于2014年提出。
论文：XGBoost: A Scalable Tree Boosting System

- XGBoost 是Gradient Boosting的改进版，属于Boosting集成学习方法，通过串行训练多个弱学习器（通常是CART回归树） ，每棵树拟合前一轮模型的残差(负梯度) ，最终加权求和得到强模型。
- 一句话定义：
  - GBDT 的高效工程实现 ，由 Tianqi Chen 于 2014 年提出；
  - 核心 = Gradient Boosting + 显式正则化 + 二阶泰勒展开 + 工程优化 。
3.2.1 核心思想
3.2.1.1 模型形式
Xgboost的最终预测模型：
$$\hat y_i=\sum_{k=1}^{K}f_k(x_i),f_k \in F$$
其中$$f_k$$是第k颗回归树，$$F$$是所有可能CART回归树组成的函数空间，K是树的总数
3.2.1.2 目标函数
XGBoost显式定义了带正则化的损失函数，正则化是 XGBoost 防止过拟合的核心机制，而传统 GBDT 没有显式正则项，其定义如下：
$$\text{Obj} = \sum_{i=1}^{n} L(y_i, \hat{y}_i) + \sum_{t=1}^{K} \Omega(f_t)$$
$$\Omega(f) = \gamma T + \frac{1}{2} \lambda \|w\|^2=\gamma T+\frac12 \lambda\sum_{j=1}^Tw_j^2$$
其中$$L(y_i,\hat y_i)$$是可微的损失函数(例如平方误差、logistic loss)，$$\Omega(f_t)$$部分是正则项用于控制模型复杂度，即由叶子结点数量和叶子结点数值的$$L2$$范数组成；
- $$T$$：叶子节点数；
- $$w_j$$：第 $$j$$ 个叶子的输出值；
- $$\gamma \ge 0$$：控制树复杂度（叶子数惩罚）；
- $$\lambda \ge 0$$：L2 正则化系数（防止权重过大）；

3.2.1.3 泰勒展开
二阶泰勒展开表达式：$$f(x)=f(x_0+\Delta{x})=f(x_0)+f'(x_0)\Delta{x}+\frac12f''(x_0)(\Delta{x})^2$$

对于提升树而言：$$\textstyle F_t(x_i)=F_{t-1}(x_i)+f_t(x_i)$$，其中$$f_t$$是第$$\textstyle t$$轮的模型，则第$$t$$轮的目标函数为：
$$Obj^{(t)}=\sum_{i=1}^{n}L(y_i, F_{t-1}(x_i)+f_{t}(x_i)) + \sum_{k=1}^{t}\Omega(f_k) $$
将目标函数进行二阶泰勒展开后得到：
$$Obj^{(t)}\approx\sum_{i=1}^{n}[L(y_i,F_{t-1}(x_i))+L'(y_i,F_{t-1}(x_i))f_t(x_i)+\frac12L''(y_i,F_{t-1}(x_i))f_t(x_i)^2]+\sum_{k=1}^{t}\Omega(f_k)$$
记$$\textstyle g_i=L'(y_i,F_{t-1}(x_i))$$，$$\textstyle h_i=L''(y_i,F_{t-1}(x_i))$$，常数项不影响优化结果可以丢掉，因此：
$$Obj^{(t)}\approx\sum_{i=1}^{n}[g_if_t(x_i)+\frac12h_if_t(x_i)^2]+\Omega(f_t)$$
由于$$F_{t-1}(x_i)$$是前一次迭代的整体结果，同时$$y_i$$已知，所以优化$$Obj^{(t)}$$等价于优化$$f_t(x_i)$$。

3.2.1.4 结构函数
带入正则项展开式，得到：
$$Obj^{(t)}\\ \approx\sum_{i=1}^n[g_if_t(x_i)+\frac12h_if_t(x_i)^2]+\Omega(f_t(x_i))\\ =\sum_{i=1}^n[g_if_t(x_i)+\frac12h_if_t(x_i)^2]+\gamma T+\frac12 \lambda\sum_{j=1}^Tw_j^2\\ =\sum_{j=1}^T\sum_{i\in I_j}g_iw_j+\sum_{j=1}^T\sum_{i\in I_j}\frac12h_iw_j^2+\gamma T+\frac12 \lambda\sum_{j=1}^Tw_j^2\\ =\sum_{j=1}^T[(\sum_{i\in I_j}g_i)w_j+\frac12(\sum_{i\in I_j}h_i+\lambda)w_j^2]+\gamma T$$
令$$G_j=\sum\textstyle_{i\in I_j}, H_j=\sum\textstyle_{i \in I_j}h_i$$，则上式可以写成：
$$Obj^{(t)}=\sum_{j=1}^T[G_jw_j+\frac12(H_i+\lambda)w_j^2]+\gamma T $$
如果我们已经确定树的结构，则$$G_j$$和$$H_j$$是确定的，但$$w_j$$是不确定的，对$$w_j$$求导并令其为 0：
$$G_j+(H_j+\lambda)w_j=0 \Rarr w_j^*=-\frac{G_j}{H_j+\lambda}$$
将$$w_j^*$$代入$$Obj^{(t)}$$，则：
$$Obj^{(t)} =\sum_{j=1}^T[G_j(-\frac{G_j}{H_j+\lambda})+\frac12(H_j+\lambda)(-\frac{G_j}{H_j+\lambda})^2]+\gamma T  =-\frac{1}{2} \sum_{j=1}^{T}\frac{G_j^2}{H_j+\lambda} + \gamma T $$
计算求得的$$\textstyle Obj^{(t)}$$代表了当指定一个树结构的时候，目标函数值可以降低多少，也就是增量的含义，一般称其为结构函数。

3.2.1.5 分裂增益
假设我们在某一节点上二分裂为两个节点，分别是左(L)和右(R)，则分裂前的目标函数是$$\textstyle-\frac12[\frac{G_L^2+G_R^2}{H_L+H_R+\lambda}]$$，分裂后的目标函数是$$\textstyle-\frac12[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}]+2\gamma$$，则对于目标函数来说分裂后的增益是（这里假设是最小化目标函数，所以用分裂前后 loss 降低的部分）：
$$\text{Gain}=\frac12[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{G_L^2+G_R^2}{H_L+H_R+\lambda}]-\gamma$$
Gain 是计算出来的增益，这个公式跟 ID3 计算信息熵增益、C4.5 计算信息增益率增益和 CART 计算基尼指数是一致的，都是用分裂后的某种值减去分裂前的某种值。
若 $$\text{Gain} > 0$$则分裂，其中$$\gamma$$起到预剪枝 作用。为了限制树的增长可以加入阈值，当增益大于阈值时才让节点分裂，上式的$$\gamma$$即阈值，它是正则项里面叶子结点数$$T$$的系数，所以 xgboost 在优化目标函数的同时也相当于做了预剪枝。另外，上式中还有一个系数$$\lambda$$，是正则项里关于叶子节点的$$ L2$$ 模平方的系数，对叶子节点的复杂度多了平滑，也起到了防止过拟合的作用，这是传统 GBDT 里面不具备的特性。

3.2.1.6 整体求解流程
对于单棵决策树，一种理想的优化状态就是枚举所有可能得树结构，然后找到一颗最优树，过程如下：
- step1: 枚举所有可能得树结构，即 q；
- step2: 计算每种树结构下的目标函数，即$$Obj^{(t)}$$的值；
- step3: 取目标最佳的树结构，使用$$w_j^*$$求解每个叶子结点的$$w$$取值，即样本的预测值；

但是因为树的结构比较多，枚举所有的树结构实际上是不不可行的，所以一般使用贪心策略来求解：尝试分类一个叶节点，计算分裂前后的增益，选择增益最大的，其过程如下：
- step1: 从深度为 0 的树开始，对每个叶子节点枚举所有可用特征；
- step2: 针对每个特征，把属于该节点的训练样本根据该特征值排序，通过线性扫描的方式来决定该特征的最佳分类点，并记录该特征的最大收益（采用最佳分裂点时的收益）；
- step3: 选择收益最大的特征作为分裂特征，用该特征的最佳分裂点作为分裂位置，把该节点生长出左右两个新的叶节点，并为每个新节点关联对应的样本集；
- step4: 回到 step1，递归执行到满足特征条件为止

所以 Xgboost 得算法可以总结为：
- step1: 算法在拟合的每一步都生成一颗回归树
- step2: 在拟合这棵树之前，需要计算损失函数在每个样本的一阶导和二阶导，即$$g_i$$和$$h_i$$
- step3: 通过上面的贪心策略生成一颗树，计算每个叶子结点的$$G_j$$和$$H_j$$，利用$$w^*$$的公式预测值$$w$$
- step4: 把新生成的回归树$$f_t(x)$$加上$$\textstyle \hat{y}_i^t=\hat{y}_i^{t-1}+\eta f_t(x_i)$$，其中$$\eta$$为学习率，主要为了抑制模型的过拟合;
3.2.2 核心优势
3.2.2.1 关键特性
- 正则化防止过拟合
  - 通过在目标函数中加入正则项，控制树的复杂度（叶子数量和权重大小），有效防止过拟合。
- 使用二阶导数（Hessian）
  - 传统 GBDT 仅使用一阶导数（梯度），而 XGBoost 使用一阶和二阶导数 ，使优化更精确，收敛更快。
- 处理缺失值：在构建决策树时，XGBoost 会为每个特征的每个分裂点（split point）同时学习两个方向
  - 当特征值 非缺失 时，按正常规则判断走左子树还是右子树；
  - 当特征值 缺失 时，XGBoost 会尝试将所有缺失样本统一导向左子树或右子树，并选择使目标函数（损失 + 正则化）下降最多的方向作为默认方向。
  - 缺失值往哪边走效果更好，就往哪边走；
- 支持稀疏数据
  - 对稀疏特征（如 one-hot 编码）有良好支持，但需要显式设置tree_method='hist'，调用直方图算法；
- 并行计算
  - 在特征粒度上并行（如排序、寻找最佳分裂点），而非树之间并行，显著提升训练速度。
- 支持多种目标函数和评估指标
  - 回归（reg:squarederror）、分类（binary:logistic, multi:softmax）、排序（rank:pairwise）等；
  - 支持自定义损失函数和评估指标。
-  高效的剪枝策略
  - 采用后剪枝(post-pruning)：先生成完整树，再从底部向上剪枝，避免贪心算法过早停止。
- 可扩展性强
  - 支持分布式训练（通过 Dask、Spark、Ray 等）；
  - 提供 Python、R、Java、Scala、C++ 等多语言接口

3.3 LightGBM
LightGBM: A Highly Efficient Gradient Boosting Decision Tree

LightGBM 算法梳理

GBDT 的主要开销在于学习决策树，而其中最耗时的部分是寻找最佳分割点。一种主流做法是采用预排序算法，而另外一种是基于直方图的算法。为了减少训练数据的规模，一种通用的方法是采用下采样算法；类似地，为了减少特征数量，可以过滤掉弱特征。因此在 LightGBM 中，提出了两种技术 GOSS（Gradient-based One-Side Sampling）和 EFB（Exclusive Feature Bundling）。
3.3.1 单边梯度采样
GOSS: gradient-based one-side sampling
样本梯度可以用来做采样信息，如果一个样本的梯度很小，则意味着该样本已经训练好了。一个至关的想法，丢弃掉梯度小的样本，但这样会改变数据分布导致精度损失。GOSS 通过保存大梯度样本，随机采样小梯度样本，并引入一个常系数来弥补数据分布影响。
先根据梯度对样本排序，选取$$a\times100\%$$的 top 样本，再从剩余数据中随机选择$$b\times100\%$$的样本，并乘以$$\textstyle\frac{(1-a)}{b}$$的常系数放大。
未采样以前计算特征$$j$$在$$d$$数值点的信息增益：
$$V_{j|O}(d)=\frac{1}{n_O}\Big(\frac{(\sum_{\{x_i\in O;x_{ij}\le{d}\}}g_i)^2}{n_{l|O}^j(d)} + \frac{(\sum_{\{x_i\in{O};x_{ij}>d \}}g_i)^2}{n_{r|O}^j(d)}\Big)$$
采样后的信息增益为：
$$\tilde{V}_{j|O}(d)=\frac{1}{n_O}\Big(\frac{(\sum_{x_i\in A_l} g_i+\frac{1-a}{b}\sum_{x_i\in B_l} g_i)^2}{n_{l|O}^j(d)} + \frac{(\sum_{x_i\in A_r} g_i+\frac{1-a}{b}\sum_{x_i\in B_r} g_i)^2}{n_{r|O}^j(d)}\Big)$$
3.3.2 互斥特征捆绑
EFB: exclusive feature bundling
将高维稀疏特征转化为低维稠密特征
高维的数据通常是非常稀疏的，可以设计一种接近无损地方法减少特征的维度。特别地，在稀疏特征空间中，许多特征是完全互斥的，即它们从不同时为非零值。通过仔细设计特征扫描算法，从捆绑特征中设计了单个特征相同的直方图，这种方式构建直方图的时间复杂度从$$O(\#data * \#feature)$$降低到$$O(\#data * \#budle)$$，由于$$\#budle<<\#feature$$因此能够极大地加速 GBDT 的训练过程而不损失精度。
有两个问题需要被解决：第一个就是需要确定那些特征应该绑定在一起，第二个就是如何构造捆绑。
对于第一个问题，设计了一种近似算法，将最优捆绑问题转化为图着色问题。给定图着色的一个实例$$G=(V,E)$$，以关联矩阵$$G$$的每一行为特征，一个实例有$$|V|$$个特征，一个独特的特征捆绑与一组具有相同颜色的顶点相对应，反之亦然。如果两个特征之间不是相互排斥，那么我们用一个边将他们连接。此外，通常有很多特征，尽管不是 100%互相排斥，也很少同时取非零值，如果允许一小部分的冲突，可以得到更少的捆绑特征，进一步提高效率。所以如果能够选择一个相对较小的$$\gamma$$时，能够完成精度和效率之间的平衡。
基于上述讨论，针对互斥特征捆绑设计了一下算法。首先建立一个图，每个点代表特征，每个边有权重，其权重和特征之间总体冲突有关。第二，我们按照降序排列图中点的度来排序特征。最后，我们检查排序之后的特征，对它进行特征绑定或者建立新的绑定使得操作之后的总体冲突最小。时间复杂度是$$O(\#feature^2)$$，并且只在训练前处理一次。为了继续提升效率，应该百万维度的特征，提出了一种更加高效的不用构建图的排序策略：将特征按照非零值个数排序，这和图节点的度排序非常相似，因为更多的非零值通常会导致冲突。
对于第二个问题，我们需要一个好的办法合并同一个 bundle 的特征来降低训练时间复杂度。关键在于原始特征可以从 bundle 中区分出来，鉴于直方图存储离散值而不是连续特征值，我们通过将互斥特征放在不同的箱中来构建 budle。这可以通过将偏移量添加到特征原始值中实现，例如，假设 bundle 中有两个特征，原始特征 A 取值[0，10]，B 取值[0， 20]。我们添加偏移量 10 到 B 中，因此 B 取值[10， 30]，通过这种做法，就可以安全地将 A、B 特征合并，适用一个取值范围为[0， 30]的特征取代 A 和 B。
EFB 算法能够将许多互斥的特征变为地位稠密的特征，就能够有效避免不必要的 0 值特征计算。实际上，我们对每一个特征，建立一个记录数据中非零值的表，通过这个表来忽略零值特征，达到优化直方图算法的目的。
3.3.3 直方图优化
Histogram optimization
基本思想是先把连续的浮点值特征离散化成 k 整数，同时构造一个宽度为 k 的直方图，在遍历数据的时候，根据离散化后的值作为索引在直方图中累计统计量，当遍历一次数据后，直方图累计了需要的统计量，然后根据直方图的离散值，寻找最优分割点。
[图片]
直方图优化算法在训练之前需要预先把特征值转化为 bin，也就是对每个特征的取值做分段函数，将所有样本在该特征上的取值划分到某一段（bin）中，最终把连续值转化为离散值。
算法过程如下：（不需要想预排序一样，把特征的所有取值进行排序）
- 首先，对于当前模型的每个叶子结点，需要遍历所有的特征，来找到增益最大的特征以及其划分值，以此来分裂该叶子结点；
- 然后：
  - 对于每个特征，首先为其创建一个直方图，存储两类信息，分别是每个 bin 中样本的梯度之和$$H[f.bins[i].g]$$，以及每个 bin 中样本的数量$$H[f.bins[i]].n$$
  - 然后，遍历所有样本，累计上述的两类统计值到样本所属的 bin 中；
  - 最后，遍历所有 bin，分别以当前 bin 为分割点
    - 累加其左边的 bin 至目前 bin 的梯度和$$S_L$$以及样本数量$$n_L$$，并于父节点上的总梯度$$S_P$$和以及总样本数量$$n_P$$，得到右边所有 bin 的梯度和$$S_R$$以及样本数量$$n_R$$
    - 根据损失增益公式计算得$$\Delta{loss}=\frac{S_L^2}{n_L}+\frac{S_R^2}{n_R}-\frac{S_P^2}{n_P}$$
    - 在遍历过程中，记录最大的增益，以及此时的特征和特征的 bin 值，作为分裂节点的特征和取值。
