降维（Dimensionality Reduction）是机器学习和数据分析中的关键技术，旨在在保留数据关键信息的前提下，将高维数据映射到低维空间 。降维有助于：
- 消除冗余和噪声  
- 加速模型训练  
- 可视化高维数据（如2D/3D）  
- 缓解“维度灾难”（Curse of Dimensionality）
常见的降维算法可分为线性与非线性 两大类。下面系统介绍主流方法，包括基本思想、数学原理、优缺点及适用场景。


---

一、线性降维算法

1. 主成分分析（PCA, Principal Component Analysis）
- 基本思想：寻找数据方差最大的正交方向（主成分），将数据投影到这些方向上，保留最大信息。
- 数学原理：
  - 对数据中心化：$$X \leftarrow X - \mu$$
  - 计算协方差矩阵：$$\textstyle C = \frac{1}{n} X^T X$$
  - 对$$C$$进行特征值分解：$$C = W \Lambda W^T$$
  - 选择前$$k$$ 个最大特征值对应的特征向量组成投影矩阵$$W_k$$
  - 降维：$$Z = X W_k \in \mathbb{R}^{n \times k} $$
- 优点：
  - 简单高效（$$O(nd²)$$）；
  - 保留全局线性结构；
  - 可用于去噪。
- 缺点：
  - 仅适用于线性结构；
  - 对异常值敏感；
  - 无法捕捉非线性流形。
- 适用场景：图像压缩、特征预处理、可视化（配合 t-SNE/UMAP 使用）。
  

---

2. 线性判别分析（LDA, Linear Discriminant Analysis）
- 基本思想：有监督 降维，最大化类间散度、最小化类内散度，提升分类可分性。
- 数学目标：
$$\max_W \frac{\text{Tr}(W^T S_B W)}{\text{Tr}(W^T S_W W)}$$
其中$$S_B$$为类间散度矩阵，$$ S_W$$为类内散度矩阵。
- 输出维度：最多$$C-1$$（C 为类别数）。
- 优点：提升分类性能；保留判别信息。
- 缺点：需标签；假设各类协方差相同（高斯分布）。
- 适用场景：人脸识别（如 Fisherfaces）、分类前的特征降维。
  

---

3. 因子分析（FA, Factor Analysis）
- 基本思想：假设观测变量由少量潜在因子线性生成，加上高斯噪声。
- 模型：$$x = \mu + \Lambda f + \epsilon$$，其中 $$f \sim \mathcal{N}(0, I)$$，$$ \epsilon \sim \mathcal{N}(0, \Psi)$$
- 与 PCA 区别：PCA 是确定性正交变换，FA 是概率生成模型，允许噪声协方差非单位阵。
- 适用场景：心理学、社会科学中的潜变量建模。
  

---

二、非线性降维算法（流形学习）

1. t-SNE（t-Distributed Stochastic Neighbor Embedding）
- 基本思想：保持局部邻域结构 ，将高维相似度转换为低维概率分布，最小化 KL 散度。
- 关键步骤：
  1. 计算高维空间中点$$i$$ 与$$j$$的相似度（高斯分布）：
  $$  p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$
  2. 在低维空间使用 t 分布建模相似度（重尾，缓解“拥挤问题”）：
  $$  q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}$$
  3. 最小化 KL 散度：$$\min_Y \text{KL}(P \| Q) $$
- 优点：
  - 可视化效果极佳（簇分离清晰）；
  - 擅长保留局部结构。
- 缺点：
  - 计算复杂（O(n²)），不适合大规模数据；
  - 超参数敏感（perplexity）；
  - 不能保留全局结构（距离无意义）；
  - 无法泛化到新样本（非参数方法）。
- 改进：FIt-SNE （加速）、Multicore-tSNE  （并行）。
  

---

2. UMAP（Uniform Manifold Approximation and Projection）
- 基本思想：基于流形假设和拓扑学理论，构建高维图并寻找低维等价表示。
- 核心假设：
  - 数据均匀分布在黎曼流形上；
  - 局部邻域可用 fuzzy 拓扑描述。
- 优点（相比 t-SNE）：
  - 保留局部 + 全局结构 ；
  - 计算更快（O(n log n)）；
  - 支持新样本嵌入 （通过 transform）；
  - 超参数更鲁棒。
- 缺点：理论较复杂；对参数（n_neighbors, min_dist）仍敏感。
- 适用场景：单细胞 RNA-seq 可视化、大规模数据嵌入（如百万级样本）。
  

---

3. Isomap（Isometric Mapping）
- 基本思想：用测地距离 （沿流形的最短路径）代替欧氏距离，再用 MDS 降维。
- 算法流程：
  1. 构建 k-NN 图；
  2. 用 Dijkstra 或 Floyd-Warshall 计算所有点对的最短路径（测地距离）；
  3. 对测地距离矩阵进行经典 MDS（多维缩放）。
- 优点：保留全局几何结构。
- 缺点：
  - 对“短路”敏感（噪声边导致测地距离失真）；
  - 计算复杂（O(n³)）；
  - 不适用于非凸流形。
- 适用场景：人脸姿态变化、运动捕捉数据。
  

---

4. LLE（Locally Linear Embedding）
- 基本思想：每个点可由其邻居线性重构，低维嵌入应保持相同的重构权重。
- 算法流程：
  1. 对每个点$$x_i $$，找 k 个最近邻；
  2. 计算重构权重$$w_{ij} $$：$$\textstyle \min \sum_i \|x_i - \sum_j w_{ij} x_j\|^2$$
  3. 在低维空间求解$$Y$$：$$\textstyle \min \sum_i \|y_i - \sum_j w_{ij} y_j\|^2$$
- 优点：保留局部线性关系；无全局最优解问题。
- 缺点：对边界点敏感；不适用于密度变化大的数据。
- 变体：HLLE（Hessian LLE）、LTSA（Local Tangent Space Alignment）。
  

---

5. MDS（Multidimensional Scaling）
- 基本思想：给定样本间距离矩阵$$D$$，寻找低维表示$$ Y$$使得$$ \|y_i - y_j\| \approx D_{ij}$$。
- 经典 MDS：当$$D$$为欧氏距离时，等价于 PCA。
- 非度量 MDS：只保持距离的排序关系 （适用于非欧氏距离）。
- 适用场景：心理学、市场研究中的感知地图。
  

---

三、基于深度学习的降维

1. 自编码器（Autoencoder, AE）
- 结构：编码器（Encoder） + 解码器（Decoder）
- 目标：最小化重构误差$$\|x - \text{Decoder}(\text{Encoder}(x))\|^2 $$
- 优点：
  - 非线性、灵活；
  - 可处理图像、文本等复杂数据；
  - 可扩展为变分自编码器（VAE）、去噪自编码器等。
- 缺点：需训练；可能过拟合；结果依赖网络结构。
  
2. 变分自编码器（VAE）
- 在 AE 基础上引入概率生成模型，隐变量服从先验分布（如标准正态）。
- 适用于生成式降维和数据生成。

六、Python 示例（sklearn + umap-learn）

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import umap
import matplotlib.pyplot as plt

# 加载手写数字数据
X, y = load_digits(return_X_y=True)

# PCA
X_pca = PCA(n_components=2).fit_transform(X)

# t-SNE
X_tsne = TSNE(n_components=2, perplexity=30).fit_transform(X)

# UMAP
X_umap = umap.UMAP(n_components=2, n_neighbors=15).fit_transform(X)

# 可视化
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, data, title in zip(axes, [X_pca, X_tsne, X_umap], ['PCA', 't-SNE', 'UMAP']):
    scatter = ax.scatter(data[:, 0], data[:, 1], c=y, cmap='tab10', s=5)
    ax.set_title(title)
plt.show()
