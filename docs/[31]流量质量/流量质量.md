# 流量质量

## 1. 风险类别

从业务类型、攻击方、受害方、作弊动机/收益点、作弊手法的组合角度划分，其中作弊动机/收益点是可以枚举的，而作弊手法则是不可枚举。

| 业务类型 | 作弊类型 | 作弊动机/收益点 | 攻击方 | 受害方 | 作弊手法 |
|---|---|---|---|---|---|
| 流量反作弊 | 恶意点击 | 恶意消耗广告主预算 | A广告主 | B广告主 | 点击软件、众包 |
| | 虚假流量 | 骗取广告分成 | 媒体 | 平台-资金损失 | 流量掺假 |
| | 激励流量 | 薅取平台补贴 | 消费者 | 平台-资金损失 | 权益任务 |
| | 爬虫流量 | 爬取商品信息 | 其他平台 | 平台-信息损失 | 爬虫点击 |
| 补贴风控 | 补贴套现 | 套取平台补贴 | 商家 | 平台-资金损失 | - |
| | 薅羊毛 | 薅取平台补贴 | 消费者 | 平台-资金损失 | - |
| | 黄牛囤货 | 低买高卖赚差价 | 商家 | 平台-资金损失 | - |

## 2. 媒体风控

### 2.1 核心目标
识别媒体端的作弊行为，保护平台和广告主的利益。

### 2.2 作弊类型
1. **流量掺假**：媒体自行或伙同第三方刷量，捏造虚假曝光/点击
2. **点击农场**：大量真实设备/人工操作，制造高转化假象
3. **众包作弊**：组织兼职人群对广告进行点击/互动
4. **激励作弊**：诱导用户完成特定广告任务（看完广告、下载App）
5. **爬虫流量**：自动化脚本抓取广告内容、商品信息

### 2.3 感知&洞察
**感知指标：**
- 维度：媒体、渠道、广告位（pid）、地域、时段
- 指标：CTR、CVR、ROI、ACPM（千次展示成本）、留存曲线
- 泰尔指数：衡量媒体间指标分布不均衡程度

**洞察指标：**
- 维度：广告主、广告计划、媒体分组
- 指标：LTV、留存率、付费转化、复购
- 序列分析：用户行为序列同质性检测
- 大模型：全域感知 + 深度分析异常媒体

### 2.4 识别框架（CE, Cause-Effect）
1. **投影（人群表征）**
   - 时序特征 → PatchTST / InceptionTime → embedding
   - 实体score：有监督广告序列模型
2. **度量（异常度量）**
   - 无监督：z-score、Chernoff界、KL散度、IsolationForest
   - 有监督：XGBoost / LightGBM 输出作弊概率
3. **集成（多维判决）**
   - 多路正交角度集成，单路保底
   - 逻辑回归 / 非负逻辑回归拟合作弊规模

### 2.5 处置&评价
**处置措施：**
- 流量过滤：直接剔除作弊流量，不计入计费
- 结算分成：按作弊比例扣减媒体收益
- 账户封禁：严重作弊媒体终止合作

**精度评价：**
- 事中：人群画像偏移分析
- 事后：广告主ROI/CVR恢复情况

**召回评价：**
- 从E侧（曝光）召回作弊流量
- 从C侧（点击）召回作弊点击

## 3. 流量质量

### 3.1 核心假设
1. **描述**：对于CPC计费流量，作弊会导致点击增多，但同时没有转化
2. **本质**：作弊会针对性做收益相关动作，不会去做后续动作
   - CPM计费作弊：曝光增加但没有点击
   - CPC计费作弊：点击增加但没有转化
   - CPS计费作弊：下单后退单
3. **总结**：由于利益驱动，只有部分作弊动作，没有正常行为动作，或者正常行为较少

### 3.2 作弊类型
1. **恶意点击**：广告主点击量突增、ROI明显降低
2. **虚假流量**：作弊媒体CVR、ROI明显低于其他媒体
3. **激励流量**：作弊渠道CVR、ROI明显低于其他渠道
4. **爬虫流量**：某些实体的CVR明显低于整体大盘

### 3.3 感知&洞察
**感知指标：**
- 维度：pid、媒体、渠道
- 指标：ROI、CVR、退单率、用户画像
- 泰尔指数

**洞察指标：**
- 维度：广告主、广告计划
- 指标：ROI、CVR、退单率、用户画像
- 可视化：降维（t-SNE）
- 大模型：全域感知、深度分析

### 3.4 识别框架（CE, Cause-Effect）
1. **投影、度量、集成**
   - 投影：人群表征（时序特征 → embedding）
   - 度量：异常度量（无监督z-score/切诺夫分数，有监督XGBoost）
   - 集成：多维集成判决（逻辑回归、非负逻辑回归）

### 3.5 处置&评价
- **处置**：CPC作弊流量过滤；媒体作弊结算分成
- **精度评价**：事中人群评价，事后CVR指标评价
- **召回评价**：从E侧召回

## 4. 补贴风控

### 4.1 核心目标
控制业务的非预期折损，包括作弊导致和机制导致。

### 4.2 作弊类型
1. 联合套现
2. 薅羊毛：零元购、黄金党

### 4.3 感知&洞察
**感知指标：**
- 维度：pid、商品、商家
- 指标：cv人、roi、核销率

**Agent → 全域风险感知：** 指标感知

### 4.4 识别框架：DNA-M（风险要素）
1. **实体**：用户、商家、商品
2. **模型**：有监督拟合

### 4.5 处置&评价
- 剔除商品、商家
- 评价：ROI

## 5. 风险要素（Risk DNA）

### 5.1 要素组成（四要素）
1. **主体（Who）**：用户、设备、商家、媒体、IP
2. **动机/意图（Why）**：套取补贴、消耗预算、爬取信息、低价囤货
3. **手法/行为（How）**：点击软件、众包、激励任务、流量掺假、退单套现
4. **影响/结果（What）**：平台资金损失、广告主预算浪费、内容信息泄露

### 5.2 划分方式（受害方 × 影响点）
| 受害方 | 影响点 | 手法 |
|---|---|---|
| 平台 | 流量 | 广告主低价拿流量（超投、刷权重） |
| 平台 | 内容 | 用户/设备爬取广告素材 |
| 平台 | 补贴 | 用户/商家联合套取补贴 |
| 广告主 | 消耗 | 用户恶意点击某广告主 |

### 5.3 风险传导链
1. 单点风险 → 链路传播 → 平台全局损失
2. 案例：商家补贴套现 → 吸引虚假用户 → 媒体流量掺假 → 广告主ROI崩盘

### 5.4 DNA-M模型应用
1. 实体：用户、商家、商品、设备、IP
2. 风险标签：薅羊毛、黄牛、套现、爬虫
3. 闭环：风险识别 → 处置 → 效果回流 → 迭代

## 6. 切诺夫界（Chernoff Bound）

### 6.1 核心价值
在大规模流量分析中，用概率上界判断指标异常是否属于小概率事件。

### 6.2 标准伯努利概率
$$\hat{p} = C_n^k p^k (1-p)^{n-k}$$
- k=n 时：$$\hat{p} = (1-p)^n$$
- k=0 时：$$\hat{p} = p^n$$

### 6.3 基于多项式展开
$$u = np$$
$$\delta = u/k - 1$$
$$\hat{p} = \exp\left(-\frac{np\delta^2}{3}\right)$$
$$s = -\log(\hat{p}) = \frac{np\delta^2}{3}$$

### 6.4 基于KL散度（最常用）
$$q = k/n$$
$$s = -\log(\hat{p}) = q\ln\left(\frac{q}{p}\right) + (1-q)\ln\left(\frac{1-q}{1-p}\right)$$

### 6.5 实战应用
1. **异常检测**：观测CTR/CVR与期望值偏离程度，计算小概率事件的置信度
2. **流量抽样**：在大流量场景下用切诺夫界确定最小采样量
3. **Campaign引爆**：检测某实体指标突然偏离，判断是否为作弊注入
4. **多重检验校正**：同时检验多个媒体/广告位，避免假阳性累积

## 7. 流量风控体系（全链路视角）

### 7.1 链路
曝光（Impression）→ 点击（Click）→ 转化（Conversion）→ 复购（Repurchase）

### 7.2 各环节作弊特征
1. **曝光层**：虚假曝光、重复曝光、可见性（Viewability）作弊
2. **点击层**：恶意点击、点击农场、点击劫持
3. **转化层**：虚假下单、退单套现、激励转化
4. **复购层**：刷单冲量、套取会员权益

### 7.3 感知-识别-处置闭环
1. **感知**：实时指标监控 + 大盘异常告警
2. **识别**：规则引擎 + ML模型 + LLM深度分析
3. **处置**：实时拦截（事中）+ 事后结算追偿
4. **评价**：精度/召回双指标体系 + 广告主反馈闭环
