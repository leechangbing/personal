    1. 数据：数据量过少，没有归一化操作
    2. 参数：学习率过大，导致震荡
    3. 结构：结构本身过于简单
  5. 解决过拟合的方法
    1. 数据：增加数据集个数，进行特征筛选
    2. 损失函数：增加正则项，L0-均匀分布，L1-拉普拉斯分布，L2-正态分布

    4. 训练过程：采用“早停”策略，提前终止
  6. 如何理解反向传播机制？
  模型训练三个重要的部件：激活函数（拟合），损失函数（评估），优化算法（调整）。前向推理过程中完成了拟合过程和评估过程，反向传播目的是根据评估结果调整参数。首先考虑单层模型：可以直接利用梯度信息来调整参数，按照贪婪策略选择最快方向，为保守起见，还要选择较小的学习率。其次考虑多层模型：使用链式规则，逐层计算梯度，再根据计算的梯度调整参数。常见的优化函数：SGD，Momentum，Resprop，Adam。
  7. 激活函数的意义
  激活函数的目的是打破神经网络的线性特性。如果没有神经网络，多个线性层可以合并为一个层，拟合能力有限。引入激活函数目的是打破线性，引入非线性，增强拟合能力。考虑到反向传播过程，激活函数都是连续可微的。
  饱和区间：输入值发生显著变化，但输出值没有棉线变化的区间。有两个问题：前向推理过程中，落入饱和区间的输出值相近；反向转播过程中，导数在饱和区间为零，几乎无法更新参数。
  8. 模型参数和超参数
    1. 机器学习：拟合输入数据到输出数值之间的映射函数，模型参数是由训练数据生成的模型值，即简单理解为系数。超参数：定义模型结构，学习率等。
    2. 学习率影响：学习率过低：收敛速度非常慢，容易陷入到局部最优点。学习率过高：容易发生震荡，难以收敛
    3. 常用术语：Epoch：表示数据集的迭代次数，Batch：一批样本的数目。

深度学习
1. Batch Normalization（BN）意义
  1. 机器学习领域有一个重要假设：Independently Identically Distribution (IID)，即独立同分布，也就是训练数据集和测试数据集是满足相同分布的。模型是建立一个从输入数据和输出数据之间的映射函数，如果输入数据发生改变，则映射函数性能会下。BN的作用就是在深度神经网络训练过程中，是每一层的输入保持相同分布。
  2. Interval Covariate Shift (ICS, 内部协变量漂移)：深度神经网络涉及很多层的叠加，每一层的参数更新会导致下一层的输入分布发生变化，经过层层叠加之间，输出层附近层的输入分布会发生剧烈变化，这就导致高层不断去适应底层的参数更新，为了训练好模型，需要保守谨慎地设定学习率，初始化权重，以及尽可能细致的参数更新策略。
  3. 随着网络成熟的加深，输入分布多次非线性变换发生改变，但是对应的标签还是一致的，即条件概率一致，但是边缘概率不同，每个神经元不再是“独立同分布”：上层需要不断适应新的输入分布，降低学习速率；下层输入的变化可能变大或变小，导致落入饱和区，过早停止；每层的更新都会影响到其它层，因此每层的参数更新策略都需要谨慎。
  4. 标准化就是将输入数据分布变换为均值方差一致的分布，能够加速收敛。在训练过程中，随着网络加深，分布逐渐移动，导致整体分布失效。激活函数的饱和区间移动，从而反向传播时底层出现梯度消失的问题，也就是收敛越来越慢的原因。
  5. 标准化的目标将大多数值落入非线性区域内，对应导数远离饱和区，加速收敛。如果直接使用标准化，则容易导致落入线性区域，相当于把非线性激活函数变成线性函数，网络表达能力下降。为了保证非线性能力，后面有对此打了补丁，先scale再shift，希望找到一个线性和非线性的较好平衡点，既可以享受非线性的表达能力，又能享受非线性区的下降速度。
2. bias和variance之间的关系
  1. Bias是指当前模型的预测值和真实值之间的偏差，不同问题的偏差评估方式不同，例如回归问题采用MSE等，而分类问题采用cross entropy。高bias表明模型准确性低，在训练和测试中没有达到较好的效果。高bias原因：数据量太少，没有归一化处理，模型结构简单，学习率过大。
  2. Variance指当前模型预测值的方差。高variance表明模型泛化性差，在训练集合中变现良好，测试集合中表现很差。原因：模型过于复杂，含有冗余部件，采取简化措施，例如ReLU，Dropout；数据量过少，没有覆盖所有分布；预处理不太完善。

特征工程
1. 特征工程：数据和特征决定一个模型的上限，结构和方法逼近这个上限
  1. 预处理
    1. 无量纲化：使不同数值规格变换到同一数值规格
      1. 方法1：min-max scale，变换到相同数据范围
      2. 方法2：standard normalization，变换到相同分布，均值为0，方差为1
    2. 连续特征离散化
      1. 方法1：one-hot编码，不过会出现同一模型而参数等价的问题
      2. 方法2：哑变量编码，包含全零的向量
    3. 缺失值计算：均值填充，众数填充，中位数填充
    4. 数据变换：引入阻尼函数，非线性变换，sqrt(x），log(1+x)
  2. 特征选择
    1. 从两方面考虑：
      1. 发散性（自身），方差大意味着信息多
      2. 相关性（特征-目标），相关性越高越有效
    2. filter：（筛选法）
      1. 方差选择：方差越大，信息越多，适用于连续数值的数据
      2. 相关系数：计算特征值与目标值之间的相关系数（皮尔逊系数）
      3. 卡方检验：统计实际观测值与理论值之间的偏离程度，若卡方值越大则二者之间的偏差程度越大，反之则越小；
      4. 互信息法：评价自变量与因变量之间的相关性
    3. wrapper（包装法）
      1. 递归特征消除法：使用一个基模型进行多轮次训练，每轮训练后消除基于权值系数的特征，在基于新的特征及进行下一轮训练
    4. embedded降维
      1. 基于惩罚项特征选择：使用L1正则项的逻辑回归模型作为基准模型，滤除掉权重较小的特征，实际上L1正则项降维的原理在于保留多个对目标值具有同等相关性中的一个，因此需要结合上L2正则化进行优化。选择L1取值为1，在L2中选择与其权值差别不大，但L1权值为0的集合，即利用L2帮助L1选择同类特征。
      2. 基于树模型特征选择：树模型中GBDT可用来作为基模型进行特征选择
  3. 降维
    1. 主成分分析法（PCA）
    2. 线性判定分析（LDA）
2. ID类特征：在推荐系统，计算广告，反欺诈风控模型中都有成功案例
  1. 为什么：提高模型的个性化能力和实际效果，对抗“热度穿透”现象
  2. 怎么用
    1. ID类特征极其稀疏，需要正则化使之不过拟合
    2. 特征组合：单独的ID类特征没有意义，不同层次的组合才有意义特征：用户ID+GPS坐标+用户喜好Tag+年龄+性别
    3. 模型和算法：实际上LR是使用ID类特征的，原因在于LR适合接受超高维度的特征输入（Embedding）
