神经网络本质上是在一个“巨大”的观测空间中，寻找一组模型参数使得输入的预测值能尽可能接近真实值；
1. 预测：预测输入数据的结果
  1. 特征抽取器：针对不同特性的数据采用不同的抽取方式，将先验信息传入模型结构中；
  2. 激活函数：提高模型泛化能力，扩大预测空间范围，然后从更大的范围中找“最优解”；
2. 评估：根据预测值和真实值之间的差距，评估估计参数的好坏
  1. 损失函数：预测值和真实值差距的度量函数；
  2. 正则化：加入参数的先验分布信息，使结构风险最小化，提高模型泛化能力；
3. 优化：沿着梯度方向优化目标函数，

1. 网络结构
对于不同类型的特征，采取不同的抽取器，
- 全连接层（Dense / Fully Connected Layer）每个输入神经元与每个输出神经元相连，用于整合特征。
- 卷积层（Convolutional Layer）利用局部感受野和权值共享提取空间局部特征，广泛用于图像处理。
- 池化层（Pooling Layer）如最大池化（Max Pooling）、平均池化（Average Pooling），用于降维和增强平移不变性。
- 循环层（Recurrent Layer）如RNN、LSTM、GRU，用于处理序列数据，保留时间维度上的依赖关系。
- 注意力层（Attention Layer）动态分配不同输入部分的重要性权重，是Transformer的核心。
- 归一化层（Normalization Layer）如Batch Normalization、Layer Normalization，用于稳定训练过程、加速收敛。
- 激活函数层（Activation Layer）引入非线性，如ReLU、Sigmoid、Tanh、GELU等。

感知机：起源于上世纪五、六十年代，拥有输入层、输出层和一个隐藏层，但无法解决复杂函数，例如异或问题。
多层感知机：上世纪八十年代人发明，拥有多个隐含层的感知机；使用sigmoid或tanh等连续函数模拟神经元对激励的响应，在训练算法上则使用Werbos发明的反向传播BP算法，解决了之前无法模拟异或逻辑的缺陷。

1.1 前馈(feedback)
- DNN: deep neural network
- 单从结构上来说，全连接的DNN和上图的多层感知机是没有任何区别的。
- 2006年，Hinton利用预训练方法缓解了局部最优解问题，将隐含层推动到了7层。
- 为了克服梯度消失，ReLU、maxout等传输函数代替了 sigmoid，形成了如今 DNN 的基本形式。
1.2 卷积(convolution)
CNN: convolutional neural network
卷积层：特征抽取，局部连接，参数共享，降低参数规模；
池化层：降低噪声，降低维度；
全连接层：特征组合，输出预测；
- 参数爆炸：通过卷积操作和权重共享，降低了全连接层的参数量级；
- 梯度消失：在2016年出现的高速公路网络(highway network)和深度残差学习(deep residual learning)进一步避免了梯度消失问题，网络层数达到了152层；
1.3 循环(recurrent)
- RNN: recurrent neural network
- 全连接的DNN还存在着另一个问题——无法对时间序列上的变化进行建模。
- 在RNN中，神经元的输出可以在下一个时刻作用到自身，即第i层神经元的在t时刻的输入，包括第i-1层的t时刻输出和第i层在t-1时刻的输出。
- RNN可以看成一个在时间上传递的神经网络，它的深度是时间的长度，“梯度消失”现象又要出现了，这次发生在时间轴上，导致误差无法传递到“遥远的过去”。
- 为了解决时间维度上的梯度消失，长短期记忆网络(long short-term memory, LSTM)，通过门的开关实现记忆功能，并防止时间维度上的梯度消失。

2. 优化算法
2.1 激活函数(activation function)
常见的激活函数（activation function）总结
增加模型的非线性表达能力，提高泛化能力；如果没有激活函数，神经网络只能表达线性映射，那么深层网络和单层网络是等价的。
- 可微性：因为优化方法基于梯度下降
- 单调性：激活函数单调可以保证单纯网络是凸函数
激活函数
特性
Sigmoid
- 数学定义：
  - 原函数输出范围(0，1)
  - 导函数可以用原函数表达，导函数输出范围（0， 0.25）
- 数学特性：
  - 饱和性：当x取值较大或者较小时导函数趋向零，导致权重参数难以更新，即便在x=0附近，五层将会衰减为原本的$$0.25^5=0.001$$，出现梯度消失问题
  - 偏移性：输出值均大于0，使得后面一层得到的输入不是零均值信号
$$\textstyle \sigma(x) = \frac1{1+e^{-x}}$$
$$\textstyle \sigma'(x)=\cfrac{e^{-x}}{(1+e^{-x})^2}=\sigma(x)\cdot(1-\sigma(x))$$
Tanh
- 原函数输出范围在（-1,1），均值为0
- 导函数输出范围为（0，1），在一定程度上缓解梯度消失问题
$$\textstyle \tanh(x)=\frac {1-e^{-2x}} {1+e^{-2x}}=2\cdot\sigma(2x)-1$$
$$\textstyle \tanh'(x)=2\cdot2\cdot\sigma(2x)\cdot(1-\sigma(2x))=4\sigma(2x)(1-\sigma(2x))$$
ReLU
- 梯度消失问题：当x>0时不存在饱和区，导数输出为1使得梯度不会衰减
- 神经元死亡问题：当x<0时存在硬饱和区，导数为0导致权重无法更新，出现神经元死亡
$$\textstyle ReLU(x)= max(0, x)$$
$$\textstyle ReLU(x)'=\begin{cases} 0 &\text {if x < 0} \\ 1 &\text {if x > 0} \end{cases}$$
Leaky-ReLU

- 梯度消失问题：当x>0时，梯度不会衰减
- 神经元死亡问题：解决了x<0时的硬饱和问题，$$\alpha$$一般设为0.25
$$f(x)=\begin{cases} x &\text {if x>0} \\  \alpha x &\text {if x < 0} \end{cases}$$
$$f'(x)=\begin{cases} 1 &\text {if x>0} \\ \alpha &\text {if x<=0} \end{cases}$$
Softmax
- 一般用于多分类函数，
$$\textstyle P=softmax(z)=\frac{e^{z_i}}{\sum_j e^{z_j}}$$
$$\textstyle \frac{\partial P_i}{z_i}=\frac{e^{z_i}}{\sum_j{e^{z_j}}}-\frac{e^{z_j}\cdot{e^{z_j}}}{(\sum_j{e^{z_j}})^2} = P_i\cdot(1-P_i)$$
$$\textstyle \frac{\partial P_i}{z_j}= -\frac{e^{z_j}\cdot{e^{z_j}}}{(\sum_j{e^{z_j}})^2} = -P_i\cdot P_j$$


2.2 损失函数(loss function)
机器学习中的目标函数、损失函数、代价函数有什么区别? - 知乎
常见的损失函数(loss function)总结
损失函数(loss function)：用来度量拟合的程度，也叫代价函数(cost function)，$$L(Y, f(X))$$
经验风险(empirical risk)：损失函数的期望，其中平均损失函数叫做经验风险，$$\frac1N \sum\nolimits_{i=1}^{N} {L(y_i, f(x_i))}$$
结构风险(structural risk)：用来度量模型复杂度，也叫正则化(regularization)，$$J(f)$$
目标函数(object function)：优化经验风险和结构风险，即$$min \frac1N \sum\nolimits_{i=1}^N{L(y_i, f(x_i))} + \lambda J(f)$$

常见分类：
损失函数
定义&特性
0-1损失函数
预测值和真实值相同为1，否则为0，用于感知机中
Hinge损失函数
$$L(Y, f(X))=\max(0, 1-y\cdot f(x))$$，如果正确分类为0否则为$$1-y\cdot f(x)$$，用于SVM中
绝对损失函数
$$L(Y, f(X)) = |Y - f(X)|$$
平方损失函数
$$\textstyle L(Y, f(X)) = (Y-f(X))^2$$，常用于回归任务
log对数损失函数
$$\textstyle L(Y, P(Y|X)) = -logP(Y|X)$$，常用于二分类
交叉熵损失函数
$$\textstyle L(Y, P(Y|X))=-\sum y_k*logP(y_k|X) = -logP(y_k|X)$$，常用于多分类

基础问题：
1. log对数函数和交叉熵损失函数是等价的
  1. log对数函数：$$\textstyle L = -\log P(Y|X)=-\sum_i\log({p(y_i|x_i)})$$
  2. 交叉熵函数：$$\textstyle L=-\sum{y_k*\log p(y_k|X)}=-y_k*\log p(y_k|X)=-\sum_i \log p(y_{ik}|x_i)=-\sum_i \log p(y_i|x_i)$$
2. 交叉熵函数与极大似然函数之间的联系和区别？
  1. 最小z化交叉熵和最大化似然是等价的
  2. 最小化交叉熵：$$\textstyle L_{CE}=-\frac{1}{N}\sum_i \log(p_{\theta}(y_i|x_i))$$
  3. 最大化似然：$$\textstyle \hat \theta_{MLE}=\argmin \sum_i(p_{\theta}(y_i|x_i))$$
3. 当激活函数为sigmod的时候为什么选择交叉熵损失函数作为损失函数？
  1. 如果选择MSE作为损失函数，
    1. 模型输出：$$\textstyle \hat y = \sigma(z) = \frac{1}{1+e^{-z}}$$，其中$$\textstyle z=w^T\cdot x$$
    2. 损失函数：$$\textstyle L_{MSE}=\frac{1}{2}(y-\hat y)^2$$
    3. 权重梯度：$$\textstyle \frac{\partial L_{MSE}}{\partial w} = (y-\hat y)\cdot \sigma'(z)\cdot x$$，其中会出现梯度消失的问题
  2. 如果选择交叉熵作为损失函数
    1. 损失函数：$$\textstyle L_{CE} = -(y\log{\hat y} + (1-y)\log{(1-\hat y)})$$
    2. 权重梯度：$$\textstyle \frac{\partial L_{CE}}{\partial w} = -(\frac{y}{\sigma(z)}\sigma'(z) + \frac{1-y}{1-\sigma(z)}(1-\sigma'(z))\cdot x =(\hat{y}-y)x$$
    3. 梯度中不包含sigmoid函数的导数项，能够缓解梯度消失问题；

2.3 正则化(reguliration)
为了防止过拟合，在目标函数中额外加入的项，L-p范数定义：$$\textstyle ||x||_p=\Big(\sum(|x_i|^p)\Big)^{\frac1p}$$
- L0正则：
  - 定义：向量中非零元素的个数，表达式为$$\textstyle ||x||_0=\sum(1|x_i\ne0)$$
  - 约束目标：很难优化求解，且与L1正则等价，因此可使用L1正则代替；
- L1正则：
  - 定义：向量中元素绝对值之和，表达式为$$\textstyle ||x||_1=\sum(|x_i|)$$
  - 约束目标：可以是权重为零，参数稀疏；
- L2正则：
  - 定义：通常意义上的模，即向量长度，表达式为$$\textstyle ||x||_2=\big(\sum(|x_i|^2)\big)^{\frac{1}{2}}$$
  - 约束目标：对绝对值大的参数惩罚大，对绝对值小的参数惩罚小，整体使权重趋向0；
